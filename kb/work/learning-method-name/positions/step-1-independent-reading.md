## Reader's response

**Confirmed reading — `gpt-6.2-astra`.** I accept *deliberative learning* as the name of a method with no success condition. I accept *learned* as a separate, strict claim about the result of one retained change. My disagreement is with condition 2 as written: a judgment **to keep** a change need not be a judgment **that it improves** future work. The draft itself permits keeping a change while that question is open.

I read the three conditions this way:

1. **Legible store.** Someone judging a change must be able to identify what was added, altered or removed. That gives later criticism an object; it does not make the effect of the change evident. A readable release note about a weight update does not make the note the store in which the model learned.
2. **Judgment governs retention.** I would say: “The named system decides whether to keep the change for its future work; the adequacy of its grounds for that decision is open to question within the loop.” A validator can settle whether a replacement link resolves. It cannot thereby settle whether the link leads readers to the right instruction. A loop that can revisit the checker’s sufficiency qualifies; an automatic merger whose rule only an outside maintainer can reconsider does not qualify on its own.
3. **Criticism can change what happens next.** I accept this condition without requiring restoration. If deleting obsolete proposals repeatedly costs maintainers information they need, the system can change its deletion rule even if an old proposal is unrecoverable. Merely logging the losses while the same rule remains beyond challenge would not suffice.

**For “learned,” the strict inequality matters.** Suppose an instruction helps on 90 later tasks and hurts on 10, relative to doing the same work without that instruction. Assume those frequencies represent the declared work and the gains are comparable in size. If every defensible valuation puts the average loss below nine times the average gain, I would report *learned*, despite the ten harms. If nine is also defensible and none is higher, I would report *better on some measures, tied on the rest*—not *learned*. If defensible valuations fall on both sides of nine, the verdict is *open because the measures disagree*, even if the counts are exact. Before those episodes, I might keep the instruction for a reversible trial; that is adoption, not any of those findings.

The comparison needs to say **against what alternative, for whose work, and over what period**. A reasonable measure must be defensible from that purpose whichever version it favors. A later release outperforming an earlier one does not establish that this instruction was learned if other changes could explain the gain.

I read the draft and its linked on-balance note in full. This is a test of the definitions, not evidence that Commonplace has learned a particular change or that a model can run its outer loop well.
