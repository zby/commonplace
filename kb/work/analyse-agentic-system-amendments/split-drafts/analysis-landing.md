# Agentic system analyses

Accepted analyses explain external systems from a frozen evidence boundary.
Each overview supplies synthesis, limitations, members and reconciliation.
Current public selection is owned by `kb/agentic-systems/reviews/` analysis
references and surfaced through that collection's reader landing. Readers and
comparison tools use the selected reference's manifest pin to identify exact
accepted evidence. Directory order and run dates do not determine selection.

Retained prior runs remain evidence; they do not automatically join the current
comparison population. Historical archives keep their producing contracts.
Working state is excluded from public output.

Promotion must add working links to the agentic-systems landing and accepted
retained overviews after migration. This draft deliberately contains no links
to destinations that do not yet exist.
