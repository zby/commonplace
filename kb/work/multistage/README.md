# Multistage writing runs

Skill-managed workshops produced by `cp-skill-write-multistage`. Each run keeps its brief, independent reconstruction, claim disposition, draft, audit, candidate, and workflow state together until promotion and any authorized handoffs are complete.

This directory is a grouping namespace, not a nested collection. Its runs inherit [`kb/work/COLLECTION.md`](../COLLECTION.md).

Active runs remain listed individually in [`kb/work/README.md`](../README.md). Delete a completed run when its outputs and handoffs have been consumed, under the normal workshop lifecycle.
