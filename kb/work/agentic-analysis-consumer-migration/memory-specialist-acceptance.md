# Memory specialist acceptance

## Commission and implemented boundary

On 2026-09-05 the operator authorized moving the memory lens to a fresh
sub-agent, retaining the useful source-analysis progression of the old memory
review. The typed report is the substantive handoff; off-band messages carry
progress and access issues, with every analytical finding retained in the
report. The operator explicitly rejected keeping legacy paths live or adding
compatibility.

The new `analyse-agent-memory` skill writes one `agent-memory-analysis-report`
inside the parent run. It owns the memory findings and proposed fourteen-axis
profile. The main procedure freezes its input, delegates that pass, integrates
proposals into canonical IDs and writes one self-contained result. Publication
retains the main result and compact review. The local report and input remain
required for local completion verification; public consumers use the retained
result without needing ignored files.

The legacy skill and its two skill projections are removed. Publication's
legacy arguments, output fields and semantic-review branch are removed, with
no alias, version switch or fallback. Existing review artifacts remain
historical evidence. Historical completion records are not rewritten to pass
the current contract. This does not complete the pending historical survey,
comparison and citation migrations.

## Mechanical acceptance

Runtime tests exercise a complete memory-system publication with the specialist
report and no legacy output, and reject missing reports, blocked reports,
wrong run/source/boundary, changed input, changed report bytes, invalid report
structure and incorrect source quotes. Shared comparison validation also
rejects off-vocabulary values, unsupported known classifications, unresolved
proposal IDs and contradictory dependencies. Report proposal IDs cannot leak
into final-result comparison fields. Existing incumbent, frozen-source and
rollback checks remain exercised. The removed CLI options are rejected.

These are deterministic checks of structure, identity and source occurrence.
They do not certify analytical truth or establish an independent semantic
review of the result.
