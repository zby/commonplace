## Debatable placements across the two chunks

The preceding [review and evidence pass](./evidence-additions-01.md) made three
boundary calls worth retaining:

- ADD-096, increasing computational autonomy, to observability: recurring
  intervention records expose which functions still require people. The note
  is mainly about autonomy measurement, so this is a secondary subject.
- ADD-161, soft context degradation, to observability: it explains why a
  fluent output and lack of an API error conceal failure. The head explicitly
  includes limits on visibility; it does not require an instrumentation design.
- ADD-093, production history, to claims-and-grounding: provenance, citations,
  and quote anchors preserve evidence for later review. The broader argument
  concerns reconstructability, so observability is the more direct fit.

This pass has three comparable boundary calls:

- ADD-114, LLM generation hiding a relaxed goal, to discovery: the qualifying
  operation is testing the reachability conjecture by trying to construct a
  witness. Routine rendering or search for an already known result would not
  qualify. This is the most contestable placement in this chunk because
  LLM reliability remains the note's primary subject.
- ADD-027, memory authority, to warranted-autonomy: the qualifying content
  allocates decisions between automation and reviewed or human approval under
  risk and verification constraints. Access control or tenancy alone would
  not qualify.
- ADD-130, Naur's human-only inference, to theory-builder: the head explicitly
  includes program theory and its boundary analyses. The tag classifies the
  note's inquiry into theory possession and later criticism; it does not
  certify that every program-theory holder meets the theory-builder definition.

Retain all six under the standing rule that a developed secondary argument or
boundary analysis can qualify. None requires broadening a head. These are
placement judgments; the notes' scientific and philosophical claims were not
independently reassessed or endorsed by adding tags.
