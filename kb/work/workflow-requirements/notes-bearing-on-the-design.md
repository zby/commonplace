# Notes bearing on the analysis design

A sweep of every note in `kb/notes/` and its definitions on 2026-10-10,
asking which claims bear on the engine, the compact plan, the prompts, the
correction and verification protocol and the records. Five scouts read
descriptions for all 392 files and bodies for about 70; this page keeps
what survived a second reading. Each row names the claim, the design
element it touches, and whether the design follows it, could use it, or
should watch it. Nothing here is decided.

## Cautions

- **Correlated verifiers add little.** [Error correction works above chance oracles with decorrelated checks](../../notes/error-correction-works-above-chance-oracles-with-decorrelated-checks.md): a verifier on the same model reading the same members as the producer is correlated; retries cannot amplify a weak verdict oracle. [Topology, isolation and verification](../../notes/topology-isolation-and-verification-form-a-causal-chain-for-reliable.md): a verifier that reads the producer's answers loses isolation.
- **Synthesis is not error correction.** [Merging propagates errors](../../notes/synthesis-is-not-error-correction.md); the synthesis needs its own verification, which it has, and must stay within the cited records.
- **Coverage is a predicate, not verification.** [Codification](../../notes/definitions/codification.md): a passing code check shows its predicate holds; the reports and docs should not call coverage "verified" beyond that. [Semantic work can be relocated, not eliminated](../../notes/semantic-work-can-be-relocated-but-not-eliminated.md).
- **A declared rule counts only with a consumer.** [Behavioral authority](../../notes/definitions/behavioral-authority.md) and [operative change](../../notes/definitions/operative-change.md): audit that every layout declaration has a consumer, and that a `declined` answer and a Limits entry are read by a later job or gate; otherwise they are inert records.
- **Volume is not effort.** [Cheap generation breaks text volume as an effort signal](../../notes/cheap-generation-breaks-text-volume-as-an-effort-signal.md): long reports hand the verifier the unperformed checking; bound what each verifier must check.
- **Workers reading untrusted sources.** [Privilege quarantine](../../notes/orchestration-needs-privilege-quarantine-not-permission-scope.md): a worker that reads the analysed system's code holds no authority beyond its output files, which the hand-out gives it; keep it so.
- **Skill discovery re-fires in every worker.** [Skill discovery](../../notes/skill-discovery-re-fires-in-every-sub-agent-context.md): prompt text that echoes a skill's description makes the worker load it; the prompt section already tells workers the authoring skills do not apply, which is the right shape.
- **Scaffolding is per model.** [Scaling absorbs scaffolding at fixed difficulty](../../notes/scaling-absorbs-scaffolding-at-fixed-difficulty-not-at-the-frontier.md): attempts and hand-holding tuned for one model should be revisited per model, not frozen.
- **Final success does not show path health.** [Final task success](../../notes/final-task-success-does-not-establish-intended-path-health.md): an acceptable member by an off-plan route passes; record or check the path, not only the output. [Selecting an output fixes bytes, not interpretation](../../notes/selecting-an-llm-output-fixes-a-result-not-its-interpretation.md).
- **Derived copies must be checked or absent.** [A derived copy of recomputable truth](../../notes/a-derived-copy-of-recomputable-truth-must-be-checked-or-absent.md): any hand-written copy of a layout fact in an instruction is the drift the derived lines remove; keep none.
- **Blockers must be actionable for their addressee.** [Actionable methodology](../../notes/definitions/actionable-methodology.md): a blocker aimed outside the producer's write scope needs a route, which `declined` partly gives.
- **Procedural missions are relaxing candidates.** [Operational signals of a relaxing candidate](../../notes/operational-signals-that-a-component-is-a-relaxing-candidate.md): a mission that prescribes steps rather than outcomes is brittle; the shrink to establish-and-challenge is the right direction.
