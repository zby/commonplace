# Workshop: Nearest existing constructions to Commonplace

## Goal

Characterize Commonplace through the existing constructions that most closely
approximate different parts of it. The comparison treats Commonplace as three
related but distinct objects: the human-inclusive theory builder operating
today, the development path by which more of its work could move from repeated
operator judgment into retained theory and machinery, and the conjectured
computational theory builder that is also a software house.

This framing was requested by the operator on 2026-09-03. It replaces the
narrower question of which existing systems are nearest to the reachability
conjecture. The conjecture remains one endpoint lens; it is not the definition
of Commonplace or the sole comparison basis.

## Working artifact

- [Landscape](./landscape.md) — relation-specific comparison across knowledge
  systems, epistemic and research systems, trace-learning mechanisms, software
  factories, self-modifying harnesses, and fixed-model learners

## Evaluation boundary

The landscape uses the local evidence corpus and the external search completed
on 2026-09-03, against repository commit
`6c73908fb7a0aab2b47284abbccd3ed763daae3b`. Evidence grades remain distinct:
code-grounded analyses, papers, official documentation, and practitioner
self-reports do not warrant the same claims. “Nearest” is always relative to a
named part of Commonplace; the workshop does not assume one scalar ranking.

Commonplace is assessed under [the declared Commonplace
frame](../../reference/commonplace-declared-frame.md). In particular, the
current system includes designated maintainers and is not computationally
closed. Repeated operator distinctions, gap diagnoses, artifact choices, and
admission decisions are possible evidence for later improvement, but their
systematic capture, recurrence detection, and conversion into candidates are
not currently automated.

## What closes this workshop

1. The comparison target and relation-specific axes are stable enough that a
   later search can update the landscape without silently changing what
   “nearest” means.
2. Stable claims about Commonplace's purpose and construction are extracted to
   `kb/reference/`; transferable mechanisms are extracted to `kb/notes/`.
3. Any external system that bears durable load has an appropriate source ingest
   or system analysis, and any dated comparison that must remain citable is
   preserved as a retained report.
4. The working landscape is either distilled into a self-standing article or
   consumed by those durable artifacts, after which this workshop is deleted.
