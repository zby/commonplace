# Workshop: Planning and delegation theory for agent work

## Goal

Turn the source-grounded comparison of mission tactics, rolling-wave planning,
real options, Dynamic Adaptive Policy Pathways, and set-based design into a
Commonplace theory of planning and delegation for agent work, then revise the
behavior-determining machinery that should consume that theory.

This workshop was opened on 2026-08-28 at the maintainer's direction. The
maintainer asked first for a durable report because the comparative evaluations
may be useful beyond the immediate implementation pass, and then for a review
of skills, instructions, code, and other structures that govern planning and
delegation.

## Governing question

When recurring predictable decisions are progressively moved into methodology,
schemas, validators, workflows, or deterministic code, how should Commonplace
plan and delegate the less predictable work that remains at the agent boundary?

The investigation must keep three layers separate:

1. what each external methodology actually says;
2. the mechanism it shares with agent work; and
3. the Commonplace rule or system change derived from that mechanism.

Vocabulary overlap alone does not warrant transfer.

## Implementation status

The source pass, comparative report, and three machinery audits are complete.
The first implementation pass has also promoted the two new theory owners,
revised the main information-boundary and costly-entrenchment owners, deployed
the universal delegation safety seam, corrected two live procedures, and added
two cheap deterministic code guards. The implementation handoff records the
exact surfaces and test results.

The completed executor-boundary and intent-framed-delegation staging workshops
were removed after their handoffs were consumed. The costly-entrenchment run is
retained only because it contains one proposed, unconfirmed retirement-cost
note. This parent workshop remains active for the larger procedure changes,
behavioral experiments, and proposal decisions that did not earn immediate
implementation.

The next work should be selected from the implementation handoff rather than
repeating the audits. In particular, do not infer that every item in the
machinery plan is authorized or equally ready: several require a named consumer,
a failure case, or target-side evidence first.

## What closes the workshop

The workshop closes when:

1. the report's durable theory claims have been promoted into the appropriate
   notes or existing notes have been revised;
2. every behavior-determining planning and delegation surface has been audited
   and dispositioned as change, deliberate non-change, experiment, or proposal;
3. authorized instruction, skill, schema, validator, and code changes have been
   implemented and validated;
4. material design decisions have been recorded in an ADR or proposal where
   required; and
5. the research report and audit have been consumed into durable library or
   system-definition artifacts, after which this workshop can be deleted.
