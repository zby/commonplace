# Reflective theory builder

> **Status:** Workshop definition, 2026-09-10.

A **reflective theory builder** is a theory builder that also develops and
revises an explicit theory of its own theory-building organization. It can use
that self-theory to change the machinery that determines how later theories
are built, tested, and revised.

Work on external theories is both useful work and a test of the current
machinery. When that work exposes a machinery limitation, the builder may
revise its self-theory, change the implicated machinery, and test the change by
returning to theory-building work.

Reflection therefore serves external theory-building competence; it is not a
requirement to build theories only about the builder itself.
