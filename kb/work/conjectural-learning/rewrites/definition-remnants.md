# Definition remnants before retiring the old ontology

This inventory accounts for the substantive sections of the two definitions
that the conjectural-learning migration proposes to retire. It maps claims;
it does not choose new scope, rename historical source language, or authorize
library edits. `Keep` means the claim already has a current working home,
`move` means a surviving claim needs an identified destination, and `drop`
means the claim belongs only to the retired definition or is superseded.

## Unique claims and parent dispositions

Most substantive content is already covered. Parent review on 2026-09-21
resolves the remaining retention choices as follows:

1. **Historical operation detail.** The old classical-object section gives
   more detail than the addressable-theory precedent: the deduction,
   abduction, and induction roles and the exact repair-operator list. The
   addressability draft retains the conclusion those details support. Keep
   the detail in the two source ingests. The lineage replacement needs only
   the bounded addressability precedent.
2. **Popper's “consequences exceed the holder” quotation.** The current
   drafts preserve interpretation uncertainty but not this quotation. It is
   lineage evidence rather than definitional content. Rely on the retained
   Popper source; no new definition or lineage paragraph is needed for it.
3. **Explanation-based generalization as a neighbouring operation.** No
   current draft repeats this exclusion. It does not discriminate
   conjectural learning and can drop from the ontology package; the cited
   source ingest preserves it.
4. **Historical vocabulary transitions.** The old word-forms section records
   dates for retiring *theory-mediated learning* and replacing *fallible
   theory*. These are not new-definition claims. Git history preserves the
   original section; the final migration commit will state the new retirement.
   Do not duplicate this chronology in the replacement definitions.

None of these dispositions changes definition scope. The old fragment repairs
below still need execution under the later migration commission.
