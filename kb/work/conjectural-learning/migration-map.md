# Proposed migration map

Scope only; adoption and library edits are outside this commission. Resolve
[the candidate's open choices](./candidate-ontology.md#choices-before-promotion)
before promotion. The map identifies direct dependencies, not every inbound
consumer.

## Changes that must agree

| Target | Disposition |
|---|---|
| New conjectural-learning definition | Take the general process directly from Popper; separate operational conditions and empirical claims |
| [Tentative theory](../../notes/definitions/theory-refinement.md#tentative-theory) | Give it an independent epistemic definition; remove addressability as a general requirement |
| [Theory refinement](../../notes/definitions/theory-refinement.md) | Keep classical symbolic machinery as a restricted computational precedent |
| [Learning by theory refinement](../../notes/definitions/learning-by-theory-refinement.md) | Retain its external, separately revisable theory loop as a scoped realization if the name remains useful |
| [Three lineages](../../notes/reflective-theory-refinement-has-three-separate-lineages.md) | Replace the classical epistemic-lineage attribution; retain useful structural and implementation comparisons |
| [Lead article](../../articles/learning-by-theory-refinement-with-fixed-models.md) | Later rebuild around Popper, then introduce fixed-model constraints; demote local editing to a possible benefit and reassess exclusions of discarded conjectures, reconstructed theories, and weight adaptation |

The smallest first bundle is the general definition, tentative theory,
restricted refinement definitions, and any direct consumers that would
otherwise contradict them, including `AGENTS.md` vocabulary. Preserve paths
where their scoped concepts remain useful. Follow with the lineage note and
article; adjust supplements only where their claims depend on the change.
This is a dependency order, not a global rename or a fixed file-edit sequence.

## Preserve and test

Keep the exporter example, [whole-system learning boundary](../../notes/the-deployed-system-not-the-model-is-the-unit-of-learning.md),
causal-use requirement, maintenance costs, records-versus-theories comparison,
and external-requirement authority. The [evidence ladder](../../notes/reflective-theory-refinement-needs-interpretation-and-retention.md#evidence-forms-a-ladder)
remains useful for retained-artifact paths. The [evidence supplement](../../articles/testing-the-theory-refinement-program.md)
keeps component attribution distinct from whole-system outcomes.

For later experiments, İşcan motivates controls separating labels from the
implemented procedure; POPPER motivates checking claim-to-test adequacy.
Neither supplies results for Commonplace's planned runs. Preserve original
source ingests and experimental records.

A promotion bundle is incoherent if it still makes symbolic formalization or
external addressability universal, equates learning with improvement, or
requires machinery reflection in every learner. Resolve those contradictions
before promotion; consistently scoped supplements can follow later.
