# Written artifacts in learning loops

Status: active.

## Goal

Determine which functions writing and written artifacts perform in learning loops, and which of those functions transfer between human practice and agent-operated knowledge systems without assuming that the two have the same mechanism or component boundaries.

The governing question is:

> What has to happen between an initially unarticulated or untested state and a later change in understanding or behaviour for writing to count as part of the learning loop?

The workshop does not assume that “thinking by writing,” “learning by writing,” or “written-artifact learning” is the right final category. It will decide whether the source cluster supports one cross-system concept, two linked concepts, or only a set of narrower mechanisms.

## Evaluation boundary

In scope:

- articulation, serialization, critique, inquiry routing, testing, stabilization, offloading, retention, activation, and later behavioural effect;
- human writing practices when they expose a function or failure mode relevant to KB design;
- agent loops that revise natural-language or symbolic artifacts and later consume them;
- evidence that distinguishes an artifact being present, selected, activated, and causally used.

Out of scope:

- general writing advice or cognitive science that does not change how an agent-operated KB would be built or evaluated;
- treating generated or revised text as learning merely because it was stored;
- assuming that human cognitive stages identify the components an engineered system should have;
- deciding the workshop's tag or durable note structure before the comparison yields an inclusion rule.

The working evaluation distinguishes three loci:

1. **Human learning** — a person's understanding or future capacity changes.
2. **Artifact adaptation** — a document, prompt, skill, or program is revised and retained.
3. **System learning** — a retained change is later activated and produces a demonstrated change in behaviour or capacity.

These loci may occur in one loop, but none implies either of the others.

## What closes the workshop

The workshop closes when it has:

- a functional account that distinguishes the operations currently bundled under “writing”;
- an explicit causal boundary between changed human understanding, changed artifact content, and changed agent behaviour;
- a decision about whether one cross-system concept is warranted and, if so, its inclusion and exclusion rules;
- a decision to create a tag, reuse existing tags, or create no tag;
- a disposition for the earlier discovery-lifecycle connection: integrate it, retain it only as a comparison, or reject it as the wrong owner;
- promoted any durable conclusions into the appropriate library artifacts, or recorded that the comparison did not warrant promotion;
- removed this workshop and its active-workshop entry after promotion or closure.

## Open decisions

- Is the common object a writing process, an inspectable intermediate, a retained artifact, or a larger learning loop?
- Which operations genuinely depend on natural language, and which generalize to symbolic artifacts?
- When does “artifact adaptation” earn the stronger term “learning”?
- Does the cluster need a new tag for routing, or are `learning-theory`, `constraining`, `deploy-time-learning`, and existing source links sufficient?
