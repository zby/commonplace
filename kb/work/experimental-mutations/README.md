# Experimental mutations

On 2026-11-25 the operator asked for a place to try changes to agent instructions before making them defaults. Each file is an opt-in change to one step of an existing task. To try one, name the file when commissioning the task. Nothing here changes the ordinary workflow.

- [Check what a note extraction adds](./check-what-a-note-extraction-adds.md) — try when turning source material into a standalone note that may add a claim of its own. The [original extraction and replay](../replaying-operator-rulings/case-5-harness-offload-competences/design.md) identified a component-attribution problem; this instruction also asks whether the job itself is necessary.

First [paired extraction trial](../note-extraction-trials/results.md): both writers examined whether a theory needs explicit storage; neither connected the strength of its acceptance test to the parent’s transfer claim. The revised instruction starts with the proposed citation sentence when the source will use the note as a premise. In the [audit-to-note trial](../note-extraction-trials/case-c.md), both versions preserved the limit already stated by the citing proposal; neither produced a materially different citation.

After a use, keep a short observation beside the candidate if it helps decide its fate: what changed in the work, or what effort bought nothing. Promote useful instructions into the procedure that needs them; revise or drop the others. Close this workshop when no candidates remain to try.
