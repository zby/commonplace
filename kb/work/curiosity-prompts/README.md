# Curiosity prompts experiment

Opened 2026-03-10 to test which prompt framings could recover a maintainer's
mechanistic objection to Decapod's claimed embedded constitution.

The experiment is complete. Its [report](./experiment-report.md) found that a
cost/benefit question recovered the target consistently in the small trial,
while broader curiosity produced more varied useful findings and none of the
tested prompts reliably reproduced the maintainer's stronger
discriminative-power question. The result informed the Curiosity Pass and the
durable note on prompt ablation.

The workshop remains active only because its exact experiment report still has
durable inbound consumers. Close it by moving that evidence to the appropriate
retained-report location, repairing those links, deciding whether any other
trial material needs retention, and deleting the workshop. Do not rerun or
generalize the small experiment merely to justify closure.
