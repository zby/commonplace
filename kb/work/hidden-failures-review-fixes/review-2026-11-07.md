No delivered result has a demonstrated defect. Three hidden problems matter.

The agent noticed only because an `rg` in the same command happened to show the other session's text. It re-applied the edit with an `assert` (L197). The concurrency was disclosed. The silent no-op was not.
3. **Runs with non-Pi workers get no advisory audit** (I5, 49178f22 L185/L212). The parcha-recall analysis ran with Opus workers. Its advisory audit was skipped because the meta-analyser supports only Pi, so none of its 18 worker attempts was scanned. The run also recovered from five first-pass verification rejections. All of this was disclosed.

**Decision this supports:**
- Recommend a design-pressure diagnosis for I5. The audit gap affects every analysis run that uses Claude Code workers, and a Claude Code scanner now exists.
- Collect one more observation for I2 before diagnosing.
- I1 is a candidate for diagnosis only if same-checkout concurrent edits recur.
