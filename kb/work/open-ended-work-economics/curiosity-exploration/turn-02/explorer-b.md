## Strongest rival and discriminating evidence

The strongest case-level rival is **operator-guided generic synthesis**: a capable model could have generated comparable revisions from task context and feedback, while project artifacts supplied vocabulary rather than distinctive search constraints. This rival accommodates successful edits, explicit citations, and downstream continuity. It is stronger than claiming the KB was never read. A mixed explanation also remains live: retained material constrained local proposals while the operator supplied global selection.

A discriminating record would connect a specific artifact passage to a proposal *before* the relevant operator correction, preserve the correction, and show how the proposal changed. If the proposal already respected a distinctive project constraint that the task statement and feedback did not supply, that would strengthen the retained-material explanation. If the constraint appeared only after the operator supplied it, credit should move toward feedback. Neither observation alone eliminates latent model knowledge or redundant causes.

A withheld or information-matched replacement comparison could test a causal difference more strongly, but none is authorized or performed. The current missing full prompt and tool-call transcript blocks retrospective attribution at that resolution. The proper result is partial: artifact change and reported contribution are recoverable; necessity, magnitude, and comparative task benefit remain unresolved.

The strongest steering rival is explanation-seeking inquiry with explicit alternatives, without compression as an additional objective. It can choose this question for exactly the same reason: successful continuation has an unresolved explanation. Compression-informed inquiry would need evidence of different prioritization, lower search cost, or better discoveries to establish added value. This case supplies none. Learning value remains real as a candidate even without immediate delivery savings.

## What acquisition must learn, and what must remain recoverable

Acquisition must learn more than whether the output passed. To distinguish these explanations it needs the task and acceptance boundary; which evidence reached the worker before each consequential proposal; actual proposal and correction text; and the outcome those corrections were meant to improve. Costs and operator effort are separate observations, currently unknown here. These are question-relative requirements, not a proposed memory store.

Three evidence states require different responses:

- **Never acquired:** no observer recorded a proposed causal input or distinction at the time. Later summaries cannot recreate it. Acquire a comparable future encounter if separately authorized; mark the historical gap.
- **Acquired then discarded:** an interaction was available during work but its recoverable record was not kept. Recollection can supply testimony, not the original sequence. The absent transcript here does not establish whether it was never durably captured or later discarded.
- **Retained but unconsumed:** the earlier episode survives in Git, even if a later worker reads only the current note. Retrieval can improve the account without new world observation. Availability does not establish that the historical worker consumed the same material.

An approximate account is not necessarily a lossy archive. A synopsis plus exact versioned artifacts can permit reconstruction of those artifacts while offering only an approximate explanation. A prose “exception” saying that the operator corrected the theory cannot reconstruct the correction's words, ordering, or context. Calling it a residual is insufficient: specify the recoverable object. Git here can recover accepted document bytes and their parent state, not the complete interaction or alternative proposals never committed. Even preserving every supplied message would not recover unobserved causal states.

Recoverability therefore protects future *questions*: later inquiry may need to ask whether an operator introduced a distinction or only selected a model-originated one. If only the final agreed wording survives, that distinction is lost regardless of summary quality.
