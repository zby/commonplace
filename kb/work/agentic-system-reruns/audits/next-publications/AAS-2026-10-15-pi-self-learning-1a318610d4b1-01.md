## Consequential findings

### Reflection and later delivery are retained, with stronger qualifications

The historical lead describes automatic task-end reflection, daily journals, a scored core index, optional Git and pre-start injection. The new synthesis retains these mechanisms while distinguishing host task completion from verified success and delivery from actual reliance.

Independent source checks: `S/extensions/self-learning.ts:1855–1992` shows a separate completion, optional repair receiving malformed output, parsing before persistence, daily append, derived-file updates, optional commit and runtime-note creation. `:2045–2100` shows automatic completion/suppression guards and later hidden-message/system-prompt return. No target execution was performed. The source supports the wired pathway, not an observed beneficial coding result. `P/synthesis.md`, “From task event to admitted memory” and “What kind of improvement is supported?”, already makes that distinction. No blocking regression found.

### Coarse context selection is not targeted retrieval or enforced consultation

The historical account's coarse selection and strict/advisory policy distinction survives. `S/extensions/self-learning.ts:1772–1838` selects configured core, latest daily files and latest monthly text, applies per-file/aggregate budgets and constructs natural-language consultation instructions. `:2066–2100` separately adds recent process notes and returns policy text. There is no query-matching input in this inspected selector, nor a read-verification gate in this hook.

`P/synthesis.md`, “From retained rules to later action”, accurately retains core/daily/monthly ordering, prefix truncation, notes outside the disk bundle cap, path-only long-term consultation and the external host/model's ownership of subsequent action. Strict mode is described as a request rather than enforcement. No additional audit-only caveat is required for this question.

### Current ranked rules are not complete historical evidence

The historical lead uses “complete rendered history” for long-term memory. That phrase is not treated as a requirement to preserve a potentially misleading claim. `S/extensions/self-learning.ts:1134–1358` shows index loading/fallback migration, score/hit/age sorting, per-kind selection, render-time stripping of `Avoid:`, normalized-key recurrence updates and long-term rendering of the current index. It does not preserve every past wording or structural source-message lineage. Migration from displayed core can lose both omitted rules and watch-out kind.

The new synthesis explicitly distinguishes current indexed rules from full history and repetition from corroboration; it also warns that daily text is already model-derived, not raw session logs. These are source-supported qualifications, not a coverage loss. Redistill/monthly behavior was considered through the public synthesis and verifier evidence; this audit did not independently retrace every maintenance branch.
