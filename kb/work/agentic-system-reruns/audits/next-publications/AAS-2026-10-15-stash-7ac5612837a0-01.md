## Discrepancy-led findings

Historical comparison was limited to [the supplied Stash account](../../../../agent-memory-systems/reviews/stash.md), dated 2026-06-05 and naming commit `93601c1f4e0fb42df99d2de33567095020fb6d7e`. I read the new overview, synthesis, boundary and final report verification completely, then checked selected consequential implementation paths and corrected record locations.

1. **Persistence and delivery coverage is retained and more precisely qualified.** The historical account describes merged ranked recall and later notes facts-first selection. Frozen `internal/brain/recall.go:27-141` allocates fact slots first, fetches episodes only for remaining slots and sorts the selected set. `internal/queries/recall.sql.tmpl` requires nondeleted embedded rows, but does not filter fact validity. Public synthesis, “Recovery and later delivery,” explicitly explains facts-first selection, row rather than token limits, absent validity/provenance in returned facts, and requested rather than unsolicited delivery. This is not a consequential coverage regression.

2. **Correction machinery is not presented as effective withdrawal.** Historical claims about invalidation, decay and supersession could suggest stronger read-side protection. Frozen recall SQL omits `valid_until`; `internal/brain/context.go:38-60` returns stored focus without checking expiry. The synthesis directly states these limitations, distinguishes conflict-list resolution from fact repair and episode deletion from derivative recomputation, and denies complete withdrawal/erasure guarantees. The historical context-expiry warning survives. I checked recall/focus directly; I did not independently re-audit every deletion consumer or schema cascade.

3. **The changed trace-fed classification has a concrete producer/consumer mechanism, not evidence of automatic transcript capture.** The historical account denies automatic raw-trace capture and withholds trace learning. Frozen `internal/brain/consolidate_failure.go:12-143` selects caller failures and recent episode texts, calls `ReasonFailurePatterns`, inserts unembedded repeat episodes and directly embedded pattern facts. Recall SQL excludes unembedded episodes; pattern facts have a direct recall route. The new synthesis explains this distinction and explicitly leaves original report formats unresolved. It does not infer authentic tool trajectories, automatic transcript acquisition or benefit from the word “episode.” This narrower implementation claim does not require preserving the old categorical verdict.

4. **Fact admission is not mistaken for truth validation.** Historical wording calls facts higher-quality and describes grounding guards. Frozen `internal/reasoner/openai.go:1032-1065` rejects verbatim/high-overlap copying, not unsupported novel assertions. The failure-pattern producer separately inserts facts without stage-one source associations or extraction checks. Public synthesis, “Maintenance proposes content; code admits it,” states both points and withholds uniform truth/provenance guarantees. No target model execution was needed or performed to inspect these predicates.

5. **Semantic refusals led to actual revisions, with public residual limits.** Stored judgments `000023-apply-report-verification-1.json` and `-2.json` refuse memory/epistemic verification for false whole-route containment and an overstated MCP testing affordance, not deterministic validation errors. The final report-verification discharges the blockers while retaining unresolved theory-condition assessment and secondary namespace targeting.
