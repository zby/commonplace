## Historical comparison and consequential findings

### 1. Capture qualification is too broad — blocker

Historical lead `kb/agentic-systems/reviews-archive/supermemory.md` is a **Vercel-wrapper-only** review, run `AAS-2026-09-25-supermemory-02`, revision `0e12f0b3a65af1cf7b03f48561f20ddf4369bc3f`. It distinguishes opt-in structured tool payloads from generic tool-role string content. That account is a lead, not proof about this revision.

At the current frozen source, `S/packages/tools/src/vercel/middleware.ts:65-84`, `convertToConversationMessages` first skips system messages, then handles string content:

```typescript
if (typeof msg.content === "string") {
    if (msg.content) {
        messages.push({
            role: msg.role as "user" | "assistant" | "tool",
            content: msg.content,
        })
    }
    continue
}
```

Only the later structured `tool-call` and `tool-result` branches, at lines 116-136, test `includeToolCalls`. The current publication's `P/synthesis.md`, “From a conversation to retained material,” instead says “excludes tool payloads unless enabled”; `P/runtime.md`, the admission paragraph, says “excludes tool payloads by default.” Neither carries the generic-content qualification. The narrower RT-RTE-conversation-save wording about tool calls/results does not repair the broader public sentence.

The source aliases call options to `LanguageModelV2CallOptions` in `S/packages/tools/src/vercel/util.ts:27-30`. I have **not** established that a normal typed SDK tool message can have string content; the source branch is not proof of an exploitable route. Conversely, no inspected admission check establishes a runtime guarantee excluding such input. Static conversion tests inspected at `S/packages/tools/test/with-supermemory/conversation-conversion.test.ts:1-210` exercise structured parts and do not decide that restriction. No target tests were executed.

**Unblock:** through the parent's authorized correction route, scope the public synthesis/runtime claim to structured tool-call/result parts and state that generic non-system string content passes without this option; alternatively, establish the applicable enforced input boundary and explicitly scope the claim to it. Reconcile the underlying capture record and verification wording as needed, then revalidate and audit the resulting exact bytes. No new hosted source or substantial system reanalysis is needed merely to narrow the wording. This audit alone does not amend the publication.
