## Consequential checks

### 1. Prompt-time retrieval is not demonstrated agent execution

The historical review describes prompt-time retrieval and pushed guidance. The current synthesis preserves that capability but explicitly limits delivered content and deployment. This is a warranted qualification, not a coverage regression established by the historical account.

Independent current-source reads: `inference/skill_usage.py:82-174` returns a formatted prompt and metadata; the rewrite call supplies singular `retrieved_plan`. `inference/prompt_formatters.py` shows AppWorld accepts both plan and base prompt; BFCL's formatter uses only skill text; tau2 uses policy and skill text but not plan. Searches of all three benchmark wrappers found `run` raising `NotImplementedError` at `appworld.py:182`, `bfcl.py:99`, and `tau2bench.py:124`. These source paths support the public synthesis's “Later requests reach prompt preparation, not a complete deployment” section. No target execution was performed by this auditor.

The overview's description also says exercised improvement and complete deployment remain unestablished. Its deterministic-check paragraph explicitly disclaims semantic certification. The main reader-facing qualifications are therefore not confined to this audit.

### 2. Provisional proposal reuse is not committed-library feedback

The historical review's general maintenance/update account does not settle this exact edge. More useful leads were semantic refusals `S/state/judgments/000023-apply-report-verification-1.json` and `-2.json`, which rejected earlier runtime and memory assertions respectively. The runtime refusal identified a false committed-epoch-library-to-atomic-extractor edge.

Independent read of `extraction/skill_extractor.py:309-398` confirms atomic prompt context is selected from `self.existing_skills`, and add/modify proposals update that map inside extraction. The read does not establish committed-library synchronization. Current `P/reconciliation.md`, “Integration dispositions and changed dependencies,” explicitly removes the earlier edge. `P/synthesis.md`, “Context recurrence and admission have different boundaries,” publicly says filtering/replacement does not synchronize the proposal map or retract rejected proposals. The traced runtime correction below corroborates an actual revision rather than an engine-only assertion. A whole-pipeline synchronization proof was not attempted.

### 3. Admission checks are operational gates, not correctness guarantees

The historical account's LLM-filter and missing-schema cautions survive and are more precise in the new synthesis. Independent full read of `filtering/base.py` confirms `GeneralFilter.filter` accepts a `good` substring; `ToolSchemaFilter.filter` accepts a `correct` substring and returns true without usable tool documents. Thus `not good` and `incorrect` are source-supported countercases, not observed bad admissions. The synthesis states those countercases and distinguishes checks from final content and actual execution.

The earlier memory refusal concerned optional checked export. Independent reads of `data/exporters.py:88-119` and `data/schemas.py:66-80` confirm the constructor passes `embeddings_config` to a dataclass declaring `embeddings`. This supports a static preflight failure deduction, not an observed exception. Current reconciliation and synthesis retain this defect while distinguishing standalone predicates and unchecked save/export. No necessary public qualification is missing on these selected paths.

### 4. Profile evidence strength was revised, not silently inherited

`S/state/judgments/000039-apply-profile-verification-1.json` refused a single wired `pull` finding that included the alternative public rewrite helper. The current `P/memory-profile.md:600-625` separates saved-library service requests (`basis: wired`) from `PlanRewriteService.get_pseudo_plan` (`basis: afforded`). The synthesis also preserves the alternative helper without treating it as repair of the service mismatch or established later delivery. This resolves the specific evidence-strength conflation; this audit did not reclassify all ten profile axes.
