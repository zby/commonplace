## Decisive semantic findings

### Lexical support is not semantic support; the public qualification is present

The legacy review's stronger language about rejecting unsupported claims is narrowed correctly. `S/src/wiki/ingest/spancheck.py` enumerates existing footnote markers, extracts adjacent fragments and compares them to raw slices using `token_set_ratio`. It does not enumerate all assertions or adjudicate entailment. `S/src/wiki/eval/ingest_eval.py::faithfulness` returns 1.0 when `extract_claims` is empty. These conclusions follow from static source inspection, not executed counterexamples.

`P/synthesis.md`, “From source documents to proposed pages,” explicitly explains both limitations and retains the separate CLI source/raw-availability selection. `P/epistemic.md` records the no-marker countercase under `EPI-RTE-ingest-measurement`. The overview description warns that lexical checks do not establish semantic truth. This is supported narrowing, not a coverage regression.

### Admission and withdrawal are path-specific, not universal guarantees

`S/src/wiki/review.py::accept_page` computes a namespace destination, uses `page_path.replace(dest)`, then optionally performs Git operations. It does not revalidate the edited content; its callable interface has no proof of an interactive human decision. This supports the public qualifications about same-name replacement, optional commits and failure after movement.

`S/src/wiki/retrieve/query.py::retrieve` loads current pages, but the ordinary fused-result branch does not require each returned ID to exist in that live map. Active available reranking filters candidates; the unavailable branch falls through to ordinary fusion. The public synthesis states both the positive current-page filtering and its nonuniversal output guarantee. It also states that query returns metadata, not bodies/spans or an answering prompt. The historical review's generic human-promotion/current-page wording should not replace these more precise conclusions.

The seed-driver alternative is public and supported by the report verifier's inspected source evidence; this auditor did not separately re-audit that full script. No corpus-wide or universal admission pass is inferred.
