**Adopt Version 1.**

1. Version 2 contradicts itself. It says a change kept because a validator passed meets condition 2, yet "What the term does not cover" excludes "retention bound to a fixed measure". Version 1 avoids this by treating a fixed measure as the single-loop special case.
2. Version 1 keeps the definition continuous, so a small change in how a system judges does not move it out of the term. The single-loop/double-loop property then carries the distinction Version 2 tries to build into the definition itself: whether the system can question its measure.
3. Version 1 places failures more precisely. Gradient training fails the first condition (weights are not legible). Version 2 blames "a loss chosen beforehand", which mixes two conditions together.
4. Version 1's condition 3 is sharper. It requires evidence against "that particular judgment", and it separates overwriting an earlier choice (a prompt replaced by a higher scorer) from finding that choice wrong. Version 2 has neither.
5. Version 1 keeps PRODIGY in the lineage as a single-loop deliberative learner. That fits the operator's ruling that the term covers all of Commonplace's learning. Version 1 also guards against misuse ("two nested loops are not double-loop", "not Argyris's full sense") where Version 2 is silent.

**What to keep from Version 2:** its basis for reducing to one measure. Version 2 allows the reduction "where one measure is the only reasonable one for a question, such as whether a link resolves", and adds that "what must stay open is the claim that this one measure is enough for the question."

Version 1 instead allows the reduction "when the system treats one measure as the only one." That departs from the on-balance note, which defines the verdict over every *reasonable* measure, not over whichever measure a system happens to use. Version 1 should state the reduction in terms of reasonable measures. It should also treat "this one measure is enough" as the conjecture that a double-loop learner can test and a single-loop learner cannot.
