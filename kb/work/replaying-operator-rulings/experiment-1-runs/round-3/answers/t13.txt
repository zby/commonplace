**Adopt Version 1.**

1. Version 2 treats any single fixed measure as an on-balance judgment whenever "the system treats one measure as the only one." The on-balance note forbids this: a measure is reasonable only if it can be defended from the purpose of the work, and no measure is selected. Version 2's own PRODIGY paragraph concedes that time was not the only measure that mattered.
2. Version 1 keeps the note's meaning. A deterministic check counts only "where one measure is the only reasonable one for a question," and the claim that the measure suffices must stay open to question. This matches the checks file's J: "without being bound to a measure it cannot question."
3. Version 2 removes that exclusion from J, so the link repairer alone (case 4), the score-bound builder (case 7) and Recuris lose the J exclusion the checks give them. Their placements would then depend on C, and the checks file asks for an explanation of any such flip, which Version 2 does not give.
4. Version 2 also moves the distinctive claim into a sub-term, "double-loop." It has to borrow that term from Argyris, narrow it, and guard it with two new misuse entries. The term itself then no longer marks what Commonplace is testing.
5. Version 2's claimed continuity is also weak. Its single-loop/double-loop split is a step change, and the boundary it smooths away is exactly the one the checks rely on.

**What to keep from Version 2:** the note under condition 3, "Later evidence must be able to count against the kept change." It distinguishes finding an earlier retention judgment wrong from overwriting it with a higher scorer. It also excludes a gate that admits once and never looks again, and a system that keeps everything. Version 1's condition 3 is vague without this, and the checks already depend on it: case 7 says the builder can "replace yesterday's winner" but not correct the judgment. When you move the note over, drop its claim that PRODIGY passes, or rephrase it so it does not imply PRODIGY alone is a member.
