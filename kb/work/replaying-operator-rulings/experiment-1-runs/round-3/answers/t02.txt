# Ten candidate changes to the deliberative learning definition

1. **Scope the deterministic-check note to the named system.** Change: in "A deterministic check is a degenerate on-balance judgment," say that a change kept because a validator passed meets condition 2 only if the named system can itself question whether that measure is enough.
   **Adopt.** As written, the note admits the lone link repairer (case 4) and the score-bound builder (case 7), which the checks place outside on J, because any fixed-measure loop can claim its measure is "the only reasonable one."

2. **Say what "each change" covers.** Change: state that condition 2 applies to the changes the named system keeps as learning in the named store, not to every write.
   **Adopt.** The checks show that KSI's placement flips depending on this reading, and Commonplace keeps some writes by default (logs, drafts) that would otherwise either disqualify it or quietly fall outside "all the learning."

3. **Fix what "learned" compares.** Change: define the comparison as a matched successor against its predecessor in a declared area of work, using the on-balance note's three choices (the alternative, who gains or loses, and over what period).
   **Adopt.** "The system without it" is ambiguous when changes interact. "Declared work" appears in the Tie verdict without being introduced, and the checks show that an unmatched comparison, such as one confounded by a concurrent solver upgrade, cannot support even a limited gain.

4. **Correct the autonomous-claim bullet.** Change: replace "judge on balance with no measure given to it" with "judge on balance, bound to no measure it cannot question."
   **Adopt.** The current wording contradicts the draft's own acceptance of validators as degenerate judgments, and would exclude an autonomous loop that legitimately uses one.

5. **Make correction a capacity in condition 3.** Change: replace "The system then corrects" with "The system can then correct," either by undoing or further changing the store or by changing how it judges later changes.
   **Adopt.** A definition should not require that every error found is in fact corrected. Case 3 and the Notes already treat C as a capacity that includes changing the next judgment.

6. **Replace "In weights, only the whole model can be judged."** Change: say instead that a weight change can be located but not read for what it says.
   **Adopt.** Adapters and targeted weight edits can be judged one at a time, so the current sentence is false. What legibility actually supplies is readable content to argue about.

7. **Hedge the PRODIGY-with-Minton placement.** Change: rewrite it as conditional on a named system and store (Minton plus PRODIGY; rules and utility formula), or move it to the checks file.
   **Adopt.** It is a placement claim resting on ingests with no retained quotes, in a section declared non-load-bearing, and it skips the boundary-naming step the draft demands elsewhere.

8. **Let "better on some measures, tied on the rest" count as learned.** Change: loosen the "learned" verdict to admit partial gains with no losses.
   **Reject.** It abandons the on-balance note's strict test, and it would reverse the checks' routing-rule example, which is deliberately reported as a limited gain.

9. **Require that retained changes be reversible.** Change: make the ability to undo a change part of condition 3.
   **Reject.** Commonplace deletes things irrecoverably, and case 3 explicitly locates C in correcting the judgment, not in restoring the file.

10. **Require a stated explanation of why a change works.** Change: add to condition 2 that the judgment must state why the change works.
    **Reject.** Case 6 keeps the definition apart from the builder definition, and adding this would collapse that overlap-without-containment.

## The three I would make

- **#1 (deterministic-check note).** It closes the loophole that lets a fixed-measure loop pass condition 2. It also resolves the contradiction with cases 4 and 7, and change #4 follows from it.
- **#2 (what "each change" covers).** Without it, the draft's stated purpose of covering all of Commonplace's learning is either false or unfalsifiable, and placements depend on an unstated reading.
- **#3 (what "learned" compares).** The "learned" verdict cannot be applied consistently until the comparison and the area of work are fixed.
