**Adopt Version 2.**

Version 1 says a retention decision "by one fixed measure" is an on-balance judgment, but the note it links defines on-balance as agreement across *every reasonable measure*. A single formula therefore counts only where it is the sole reasonable measure, which is what Version 2's "degenerate" bullet says. Version 1's own background contradicts it here: PRODIGY "could not ask whether time was the only thing that mattered," so its formula was not the only reasonable measure, and calling its retention an on-balance judgment misuses the linked term. Version 1 argues that the term should be continuous, but it does not remove the break. It moves the break to the single-loop/double-loop line, which turns on the same capability Version 2 uses for J (questioning the measure). It also makes "deliberative learning" cover nearly every gated optimizer, so the term stops separating anything. Version 2 also matches the existing checks: case 4's lone repairer, case 7's score-bound builder and Recuris all stay outside on J. Version 1 would flip all three, and it gives no explanation beyond the continuity argument.

**Keep from Version 1:** the Open-to-criticism bullet "Later evidence must be able to count against the kept change." It distinguishes a loop that overwrites its earlier choice (the prompt replaced whenever a variant scores higher) from one that finds that choice wrong. It also excludes both the admit-once gate and the keep-everything system. Version 2's condition 3 is thin without it, and the checks already depend on the distinction ("can replace yesterday's winner, but cannot correct the judgment"). Version 1's sharper wording of condition 3, "bring evidence against that particular judgment," should come with it.
