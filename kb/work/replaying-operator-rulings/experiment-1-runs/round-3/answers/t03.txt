**Adopt Version 2.**

1. Version 2's second condition matches the check file's J ("without being bound to a measure it cannot question"). Under it, the fixed-gate cases keep their placements: the link repairer alone, the score-bound builder in case 7, and Recuris. Version 1 would let all of these in as single-loop learners, and it gives none of the explanation the check file asks for when a placement flips.
2. Version 1's argument that a fixed measure is "the special case" misreads the on-balance note. That note makes a measure reasonable because of the purpose of the work, not because a system "treats one measure as the only one." A rule kept because a formula scored it above zero is therefore an on-balance judgment only if that formula is the only reasonable measure. Version 2 says exactly this: "where one measure is the only reasonable one… what must stay open is the claim that this one measure is enough."
3. Version 1's own account of PRODIGY works against it. PRODIGY "had no way to ask whether time was the only thing that mattered," which is precisely why its formula cannot stand in for an on-balance judgment.
4. Folding fixed-measure learners into the term pushes the distinction the project cares about into an add-on qualifier. Version 1 then has to borrow Argyris's "double-loop" in a narrowed sense and add two misuse entries to keep that qualifier from being misread. Version 2 draws the same line in the conditions themselves.

**Keep from Version 1:** the note "Later evidence must be able to count against the kept change." It separates overwriting an earlier choice (replacing a prompt whenever a new variant scores higher) from finding that choice wrong (PRODIGY revising its estimate of one rule and dropping it). It also states that a gate that admits once and never looks again fails, and so does a system that keeps everything. Version 2's third condition needs that distinction, and check cases 3 and 7 already rely on it ("can … replace yesterday's winner, but cannot correct the judgment"). Bring along Version 1's wording of the condition, "bring evidence against that particular judgment," as well.
