**Adopt Version 2.**

1. Version 1's condition 2 admits a judgment made "by one fixed measure," because "the system treats one measure as the only one." That conflicts with the on-balance note, and with Version 1's own "When a change was learned" section, where "no measure is selected" and a measure counts only if it is defensible from the purpose of the work. A system's choice to treat one measure as sufficient is exactly the narrowing the note says "smuggles a weighting back in."
2. Version 2 states the degenerate case the way the note allows: a deterministic check reduces the judgment only where one measure is the *only reasonable* one, and the claim that it suffices must stay open.
3. Under Version 1, every score-gated loop on a legible store would satisfy condition 2, so S and C would do all the sorting. Version 1 then has to admit that the term says nothing about what Commonplace adds. In Version 2, the term itself marks the boundary the project's conjecture is about.
4. Version 2 gets PRODIGY and the model-training team right with fewer moving parts. PRODIGY alone is outside, and PRODIGY together with Minton is inside. Gradient training fails on both S and J. The single-loop/double-loop vocabulary, its departure from Argyris's usage and its extra misuse entries are no longer needed.
5. The existing checks (cases 4, 5 and 7, and the Recuris placement) already follow Version 2's reading of J, so adopting it requires no reclassification.

**Keep from Version 1:** the bullet "Later evidence must be able to count against the kept change," together with condition 3's wording "bring evidence against that particular judgment." The bullet says that a loop which replaces a prompt whenever a new variant scores higher overwrites its earlier choice; it does not find that choice wrong. It also says that a one-time gate fails condition 3, and so does a system that keeps everything. Version 2's weaker "can criticize it and find it wrong" loses this distinction, which the checks' joint analysis of case 7 relies on: "replace yesterday's winner" is not "correct the judgment." Version 2 also dropped PRODIGY as the positive example in that bullet. Swap in a judgment-level example, because PRODIGY alone now fails condition 2.
