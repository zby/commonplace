## 1. Make condition 2 a deliberated decision to keep, not an on-balance verdict, and scope "each change"

**What to change.**
- **Draft, condition 2.** Replace "an on-balance judgment that the change improves the system's future work" with wording like: "a decision to keep the change, made by weighing reasons about the system's future work."
- **Draft, quantifier.** Replace "each change" with "each change offered as learning," so that logs and scratch writes in the same store fall outside the term.
- **Note.** Add a sentence separating the act of weighing (an *on-balance judgment*, which is a preference or decision) from the verdict *improvement on balance* (every reasonable measure favors the change).
- **Checks.** Mark the "Which writes count as changes?" item as resolved by the new wording.

**Reason.** The linked note defines "on balance" as every reasonable measure agreeing, and the draft says "Open" is the usual verdict when a change is kept. Read literally, condition 2 therefore almost never holds at the moment of retention, and the draft's own rule that keeping is a decision cannot be squared with it. The note shows the same slip when it answers "on balance, yes" for Python 3.11 despite a loss on `getargspec`, which is "Open" under its own definition.

## 2. Restate the fixed-measure clause as "a rule the loop cannot question," and qualify the validator bullet

**What to change.**
- **Condition 2.** Replace "not bound to one measure fixed beforehand" with "not bound to any admission rule, of one test or several, that the same system cannot question or override." This is the checks' wording for J.
- **Validator bullet.** Amend "a change kept because a validator passed meets the condition" to add "provided the named system can also revise or override that validator," and cite case 4.
- **"Does not cover" list.** Change "one formula" to match.

**Reason.** As written, a gate built from several fixed tests escapes "one measure," yet the checks exclude Recuris for exactly that ("several tests in a fixed rule are still a fixed rule"). The unqualified validator bullet also admits the link repairer that case 4 places outside. The distinctive bet that a language model can judge without a fixed measure belongs in the autonomous claim, not in a loose boundary condition.

## 3. Fix the genus: "a way of learning," not "learning that meets three conditions"

**What to change.**
- **Opening sentence.** Change to "Deliberative learning is a way of learning: a process in which…"
- **"Does not cover" list.** Say that "learning in general" (Simon's lasting change in capacity) names outcomes, while this term names a process. A run of the process can produce no learning.

**Reason.** The opening says deliberative learning *is* learning. The no-success-condition paragraph says a run that improves nothing still counts. Under the Simon sense the draft itself cites, that run is not learning at all, so the opening sentence and that paragraph contradict each other.
