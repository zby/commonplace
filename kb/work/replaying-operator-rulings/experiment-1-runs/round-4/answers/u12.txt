**Adopt Version 2.**

1. The linked note defines "on balance" as agreement across *every reasonable* measure, where reasonableness is argued from the purpose of the work. It also warns that narrowing that set to force agreement "smuggles a weighting back in." Version 1 says the judgment reduces to one measure "when the system treats one measure as the only one," which lets the system's own stipulation do exactly that narrowing, so its condition 2 contradicts the note it cites.
2. Version 2's degenerate case applies only where one measure is the only reasonable one, such as whether a link resolves, and it keeps open the claim that the measure suffices. That is the note's own reading, and it still admits Commonplace's validators, through the team-plus-repairer boundary.
3. Version 1's stated motive is continuity, so that a small change in how a system judges does not move it out of the term. But the cost is a single-loop/double-loop split, a narrowed reading of Argyris's terms, and two extra misuse entries.
4. Even then, Version 1's autonomous claim turns out to be about double-loop learning. So the content the project cares about is what Version 2 puts directly into condition 2.
5. The checks file already encodes Version 2's J (case 4, case 7 and the Recuris row), so adopting Version 2 keeps those placements stable. Version 1 would flip them without any new facts about the systems.

**What to keep from Version 1:** the bullet "Later evidence must be able to count against the kept change." It separates a loop that *overwrites* an earlier choice when a higher-scoring variant appears from one that *finds that choice wrong*. It also excludes a gate that admits once and never looks again, and a system that keeps everything. Version 2's condition 3 ("can criticize it and find it wrong") has no such test, yet the checks file relies on exactly this distinction in case 7 ("can … replace yesterday's winner, but cannot correct the judgment") and in the Recuris row.

Two things should come with that bullet:
- Version 1's wording of condition 3, "bring evidence against that particular judgment."
- The PRODIGY example. Under Version 2, PRODIGY passes C but fails J, which shows that the conditions are independent.
