**Correction:** `tests/scenarios/write-a-note.md` is wrong to say installed projects "copy COLLECTION.md and the type-specs, so the overhead files and paths match". In installed projects the library is read in place from the package, located through `.commonplace/library.md`, so `cp-skill-write/SKILL.md`, `types/note.md` and methodology escalation (the library's `theory/`, not `commonplace/kb/notes/`) resolve to library paths, and only the starter `kb/notes/COLLECTION.md` is project-local. **Consequence:** a maintainer running `kb/instructions/evaluate-scenarios/` checks each fork's load table against the live files, and in an installed project `kb/types/note.md` and `kb/instructions/cp-skill-write/SKILL.md` don't exist, so the budget check fails or measures the wrong bytes; the "identical forks" variant must list the library paths plus a possible read of `.commonplace/library.md` (not needed in Claude Code).
