# Memory refresh synthesis trial — 2026-09-26

Historical initial pilot, before ADR 093 adopted per-value evidence. The results,
contracts and counts below belong to that frozen first trial.

This workshop trial compares who selects retained context, who changes it, and what checks justify later reliance. The explicitly selected population is Napkin, Mem0 and Dynamic Cheatsheet: three current analyses, all code-grounded (3/3), with cutoff 2026-09-26. Their boundaries differ: Napkin's product includes shipped skills but excludes its external host; Mem0 covers synchronous Python OSS memory; Dynamic Cheatsheet covers local memory and a benchmark controller with external model execution. This is a bounded comparison, not coverage of the legacy corpus.

Napkin leaves the next read with the caller. Its executable route returns a requested folder map, lexical search ranked with backlinks and recency, or full note text. Its distill and tend skills instruct an external agent to extract durable notes, merge overlap and identify contradictions. Those maintenance routes are **afforded**: code supplies file operations, but the host must invoke the skills and the model must follow them. A requested overview containing project context remains pull; excluded host injection cannot supply a push claim. Persistence and retrieval are wired, while compliant distillation and later behavioral use remain uninspected. See Napkin's [shared records](../../reports/retained/agentic-system-analysis-archive/AAS-2026-09-26-napkin-01/result.md#shared-records), RTE-2, RTE-3, RTE-4, RTE-5 and BAP-1.

Mem0 wires retained context into its own next extraction call. Inferred add selects recent messages by scope identity and old memories by embedding similarity, then supplies their text to the extractor. Both extracted facts and procedural summaries can enter that later context. This is push to the extraction model; requested SDK retrieval affords a separate pull route to an application. The inferred factual route appends memories rather than automatically revising or deleting existing facts. Explicit maintenance has separate APIs. Structural admission, exact-text filtering and nonempty-summary checks do not establish truthful extraction or faithful summarization. Expiry also differs by consumer: ordinary search can hide text that internal extraction still receives. These are static implementation findings, not observed downstream benefit. See Mem0's [shared records](../../reports/retained/agentic-system-analysis-archive/AAS-2026-09-26-mem0-01/result.md#shared-records), RTE-1, RTE-3, RTE-4, RTE-5, RTE-6 and BAP-1.

Dynamic Cheatsheet owns a different recurrence: cumulative mode solves, then replaces its sheet; retrieval-synthesis selects previous examples and constructs guidance before the next solution. The generator and curator receive selected context automatically. Whole-sheet replacement is wired, while requested semantic maintenance remains **claimed**. Benchmark targets score answers after memory assignment and cannot veto that assignment. A sampled retained artifact records answer 15 against target 315, stores the answer-derived rectangle strategy, and includes the previous sheet in the next generator prompt. This establishes **observed artifact contents and recorded delivery**. It does not establish that recalled content caused the next answer, or that the generating execution used the inspected revision. See Dynamic Cheatsheet's [shared records](../../reports/retained/agentic-system-analysis-archive/AAS-2026-09-26-dynamic-cheatsheet-01/result.md#shared-records), RTE-1, RTE-2, RTE-4, RTE-8, CLM-3 and ABS-1.

The comparison therefore supports named mechanisms and evidence limits. Automatic trace-fed writes with later consumers are wired in Mem0 and Dynamic Cheatsheet and afforded by Napkin's skill route; this classification does not establish improved capacity. No comparative causal benefit is established. No prevalence, performance ranking, trend, or Commonplace recommendation is inferred. Mem0's learning horizon and timing remain not-determinable; Napkin's mixed unions often have afforded basis; Dynamic Cheatsheet's curation union has claimed basis. Unknown assessments cannot become negatives. Derived feature counts and their exclusions are retained separately in the [query ledger](./query-ledger.md). A full refresh needs separately verified population coverage and consistent field interpretation.
