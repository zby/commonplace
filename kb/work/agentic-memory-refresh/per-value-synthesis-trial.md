# Automatic memory writes cover different work

This bounded comparison finds automatic writes in all three selected systems, but their supported mechanisms differ: revising problem-solving guidance, extracting conversational facts, and rebuilding access data. The useful contrast is what gets changed and who consumes it afterward.

This is a **current-input workshop trial in temporary-bundle mode**, not a public landscape publication. Selection is explicitly one generated review each for Dynamic Cheatsheet, Mem0 and Napkin; all other systems and the legacy corpus are excluded. All 3/3 results are code-grounded, with analysis cutoff **2026-09-26**. The lens covers memory accumulated or changed through use, its access structures and later consumers. Boundaries differ: Dynamic Cheatsheet’s workflow includes opaque provider state; Mem0 covers synchronous OSS memory with default adapters; Napkin covers the package and optional skills, excluding their host executor.

Automatic write membership is **3/3 selected systems**. Trace-derived writing and push each have positive witnesses in **2/3**: Dynamic Cheatsheet and Mem0. Dynamic Cheatsheet has partial coverage on these axes; Mem0 has known coverage. Napkin’s trace extraction is afforded, and its known package read-back profile is pull-only. Its push signal is inapplicable. These dispositions are not observed negatives about excluded hosts. No relevant row is uninspected.

Dynamic Cheatsheet’s supplied curator templates direct replacement of retained guidance from solution trajectories; subsequent generator calls receive that guidance automatically. Template configuration matters: an omitted curator path supplies literal `(empty)`. Its Shared records **RTE-2, RTE-3, RTE-6** establish transformation, supply and persistence. **CLM-4** observes a wrong answer retained and delivered in later recorded prompts; the generating revision and later model dependence remain unknown.

Mem0’s **RTE-1, RTE-5 and BAP-1** instead wire new fact extraction from messages, with prior facts and recent messages automatically supplied to the next extractor. This is push to an internal extraction model; external answering use is only afforded by **RTE-3/BAP-2**. Ordinary extraction adds facts. Caller-directed replacement and deletion belong to **RTE-2**. These Shared records prevent equating accumulation with automatic correction.

Napkin’s automatic-write witness is **RTE-6**: requested access regenerates and persists caches. Its Shared records **RTE-3/RTE-4** afford semantic distillation and upkeep through an external skill agent. Wired cache generation cannot upgrade that extraction route. **RTE-1/RTE-7** implement requested returns, leaving subsequent agent use outside the package.

Natural-language and symbolic memory have positive witnesses in **3/3**, but only **2/3** representation profiles—Mem0 and Napkin—have known coverage and strong evidence for every member. Dynamic Cheatsheet’s opaque included state prevents completeness. Faithfulness is not-determinable in **3/3**; **0/3** qualify as evidenced “no.” Unknown and partial coverage do not mean absence.
