# Assessment: On-balance judgments can guide improvement without a global measure

**Purpose (operator's):** Explain how on-balance judgments guide decisions without a global measure, and where analysis helps or stops.

**What reads well:** The contrasting worked cases (Python 2/3 text handling, the `random.py` diagnostic, the 3.10/3.11 release table and the `AGENTS.md` routing line) make the method visible. Each states which work changed, for whom and why it matters, and each marks the boundary of what it settles.

**Sentence a hostile reviewer would attack first:** "A partial order can represent the preferences we can defend under a consistent set of priorities." Three depth 1 reports attack it (friction, critique and premise decomposition). A partial order requires transitivity. The note does not say where the "consistent set of priorities" is declared before a change is judged. It also does not say whether priorities that consistent amount to the weighting the note says it does without. This is a claim question (below), not a pass item.

**Overall:** The thesis and argument structure stand. No report shows a defect that needs a different thesis, a split, a merge or a reordered argument. The highest-value changes are placement and wording: the library-hours case interrupts the release section, the general rule arrives after three examples, and two support sentences overreach. Several one-sentence claim gaps go to the operator.

## Claim questions for the operator

1. **Partial order and consistent priorities.** Passage: "A partial order can represent the preferences we can defend under a consistent set of priorities." Possible defect with two readings. Under one reading, "consistent" guarantees transitivity, which approaches the weighting the note disclaims. Under the other, the defended pairwise preferences can cycle: speed favours A over B, compatibility favours B over C, library support favours C over A (premise decomposition). The note also does not say where the priorities are declared before a change is judged. The linked declared-objective note makes that declaration the condition that separates improvement from post-hoc fitting (critique). One sentence could state transitivity and antecedent priorities as conditions of the representation. Reports: `kb/reports/state/review/results/kb/theory/on-balance-judgments-can-guide-improvement-without-a-global-measure.md/kb/instructions/premise-decomposition-gate.md`, `.../kb/instructions/critique-note.md`, `.../kb/instructions/composition-friction-gate.md`. The partial-order paragraph also holds finding-4's second trim ("does not do the weighing") and synthesis opportunity 3. Both wait on this decision.
2. **Reversal rule when investigation cannot settle the unknown.** Passages: the bold investigation rule, and "If the evidence supports only the routing gain, leave the overall judgment open." The rule covers two cases: act when the preference survives every plausible answer, and investigate when a plausible answer could reverse it. It does not cover an uncertainty that could reverse the choice but that investigation cannot settle. Future use is such a case, and the note itself says an estimate "cannot settle" it. "Leave the overall judgment open" does not say whether to keep the change while a decision is due. The description promises this coverage. One sentence on the default would close the gap (finding-7, `.../semantic/completeness-boundary-cases.md`). Two related points are hard to classify as defect or extension and are treated as choices: the reversal test may need a range of weightings as well as facts (critique), and how plausibility ranges are set (premise decomposition, friction). A preference that flips between acceptable weightings would then be a value disagreement to escalate, not an unknown to investigate.
3. **Scalar reading of the Commonplace objective.** Passage: the objective sentence. Read literally, "knowledge work for the human judgment spent" is a ratio, a global measure in form (critique, premise decomposition). An added sentence could say the ratio fixes the direction of preference and is not operationalized as a score. That would leave the relied-on sentence intact, so it needs no stop. The role report notes a related wording gap: `ablation-baselines-for-the-declared-objective.md` measures "human effort" where the note says "judgment spent". The operator decides whether to name observable components.
4. **Move the Commonplace objective to `kb/reference/`.** Choice, no defect shown (finding-5, `.../kb/theory/COLLECTION.md`). Not ranked first. The operator's must-keep list holds the anchor that four references use, and the section is honestly scoped. The operator may decline.
