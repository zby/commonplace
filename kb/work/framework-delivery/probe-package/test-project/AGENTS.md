# Test project

This project uses the delivery-probe library. The library is not stored in this project.

- `cp-delivery-probe-library` prints the library root. Instructions are under `instructions/`, types under `types/`.
- `cp-delivery-probe-instruction <name>` prints the path of one instruction; run it without a name to list them.

When asked to follow a delivery-probe instruction, find it this way, read it, and follow it.
