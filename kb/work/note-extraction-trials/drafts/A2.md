# The Bitter Lesson leaves open whether learned theories need explicit retention

The Bitter Lesson favors methods that can use more computation for search and learning over methods that rely on people to encode domain knowledge. A learner that proposes a theory, derives predictions from it, and tests them against observations is doing search and learning. Writing down the theory it discovers does not turn it into a rule supplied by a designer. This answers an objection to the method; it does not establish that the method will scale well.

The narrower question is what writing the theory down contributes. A larger model might search, assess, and revise candidates internally, without storing any candidate as a separately identifiable object. For example, given the same build history and the same new failure, a model might correctly narrow a test exemption to files that no build step reads. Getting that decision right would not by itself show that the model had to retrieve and edit a stored rule. Nor would one correct decision show that the revision survives into the next session.

To test the value of explicit retention, compare what the two pathways can do with the same evidence and comparable computation as model capacity and context grow. Does a correction still guide later sessions? When one condition changes, can the learner narrow the exemption without disturbing unrelated rules? If another process must inspect the correction, can it identify which condition changed? An explicit record gives these operations a target; it does not guarantee that the correction is sound. Whether the record still helps at scale depends on which operations the task requires and how well the alternative performs them.

## Proposed citation sentences

**Theory-mediated learning may improve sample efficiency under structured shifts:** Searching for theories is compatible with the Bitter Lesson; whether [retaining a theory explicitly](../work/note-extraction-trials/drafts/A2.md) saves target observations beyond what a scaled model could achieve from the same evidence remains an empirical question.

**Theory-mediated self-improvement needs both interpretation and retention from one substrate:** For a theory about the system’s own operation, [the open question about explicit retention](../work/note-extraction-trials/drafts/A2.md) is whether a separate record still helps a correction persist across sessions, lets the system revise just its scope, or lets another process inspect it as model capacity and context grow.
