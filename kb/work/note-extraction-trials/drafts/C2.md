# A change in applicability can leave consumer, channel, and force unchanged

The [six-path Commonplace audit](../../../reports/retained/six-commonplace-paths-establish-broad-addressability-not-completeness.md) found that the explanatory-reach review gate applies only to notes with the `title-as-claim` trait. Suppose that restriction were removed. A reviewer would still receive the same audit trigger through the same review channel. What would change is whether a note *without* the trait falls within the gate’s target cohort.

The tag-README validator illustrates a change in the activation condition rather than the target. An affected marked tag head is still the target of the check. The audit records an extension that let validation of an ordinary tagged note trigger the check on that head too. Naming the validator, the validation channel, and the force of the check would not tell a reader whether validating the ordinary note was enough to trigger it.

To distinguish these uses, a reader needs to know what the rule applies to and when it acts. That information need not occupy a fourth field: qualifying the review path with “only for notes with `title-as-claim`,” for example, resolves the cohort question without changing the three fields. The cases establish what a comparison must distinguish, not where an inventory must record it.
