# Position format

One file per position. Keep it short enough to compare against the others.

```
# Position <letter>: <one-line remedy>

Author: <agent or person>, <model id if an agent>, <date>
Source: <where the position was first stated, if not here>

## Diagnosis
What is wrong, with file and line references.

## Remedy
The rule, and the concrete edits per artifact.

## Answers
D1 … D8, one line each, or "no view".

## What would change this position
An observation or argument that would make the author drop or revise it.

## Against other positions
Specific disagreements, by position letter and decision point.
```

A position recorded on behalf of an agent that is not present says so under
Author, and that agent may replace the file.
