## Settled: exactly specified structure

Tarski says the problem of truth has a precise meaning only for languages whose structure has been exactly specified: which expressions are meaningful, which terms are undefined, what the rules of definition are, which expressions are sentences, and under what conditions a sentence may be asserted. For natural, spoken languages the problem is vague and its solution can only be approximate. This is the precondition the clerk conjunct of the [commitment account](./codification-as-commitment.md) assumes: a reference a clerk could follow presupposes a language whose sentences and assertion conditions a clerk could recognize. Tarski states it as a precondition, not a result.

## Open: semantic closure and the metalanguage

Three properties must be kept apart here, because the first draft of this thread ran them together. *Formalizability* is exactly specified structure; arithmetic and programming languages have it. *Undefinability* is Tarski's theorem: a consistent exactly specified language that can name its own sentences cannot define its own truth predicate, so truth for it is defined in an essentially richer metalanguage. Arithmetic has this property, and it is a consequence of being formalized and consistent, not a failure of formalization. *The antinomy* hits only a language that is exactly specified, classical, fully disquotational and semantically closed, that is, one that contains its own truth predicate for its own sentences. Arithmetic is not semantically closed, which is why it is consistent. Everyday language appears to be, which is why Tarski guesses that an exactly specified language resembling it would be inconsistent.

The ingest's limits on what this gives the workshop follow. Undefinability holds for arithmetic and for programming languages, so it cannot be what separates them from natural language. The 1944 paper never mentions computation or execution. The defensible core is narrower: natural language cannot be formalized while keeping universality, classical logic and full disquotation together, so one of them must go, and every formalization of a fragment drops universality. A further question the ingest raises for the thread: a programming language can contain its own interpreter, as Lisp does, without contradiction, because an evaluator fixes execution rather than truth and a partial function has no liar. Whether "operationally closed but not semantically closed" is the precise form of the programming-language side is open.

## Open: universality, which is in the 1933 monograph

The claim that colloquial language is universal, that whatever can be said can be said in it, so that it absorbs any metalanguage, is in the 1933 monograph, not the 1944 paper. The structural conjecture that depended on it stands or falls with that text, which has not been ingested: a programming language's reference is stated outside it, in a metalanguage of English, mathematics and a machine, while a reference for natural language has nowhere outside to stand except a machine adopted by stipulation or a restriction to a fragment with exactly specified structure. The redefinition feature in the [tentative theory](./where-meaning-is-settled.md), that the semantic vocabulary is inside the language, is this universality seen from the speaker's side. Until the monograph is ingested, this is a conjecture attributed to Tarski by reputation, not by quotation.

## The library audit

For everyday language Tarski says the consistency question "has no exact meaning", and he only risks the guess that an exactly specified language resembling it would be inconsistent. The library's note on [underspecified instructions](../../theory/agentic-systems-interpret-underspecified-instructions.md) currently appeals to "Tarski, Gödel and halting-style impossibility results" in one breath, and the [institution-theory workshop](../institution-theory-import/import-assessment.md) flagged that appeal for this audit. The ingest's assessment is that the appeal can draw the hierarchy of languages and the absence of a general truth test, and cannot draw a theorem about natural language. That paragraph should be rewritten to the narrower claim once this thread settles, with the four passages the ingest names retained as quotes.
