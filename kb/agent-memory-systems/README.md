# Agent Memory Systems (historical survey)

For current analyses and comparisons, start at [Agentic Systems](../agentic-systems/README.md). This collection is frozen. Cite its reviews for what they observed at their recorded source revisions, not as descriptions of the systems today.

If you followed a historical citation:

- The [systems table](./systems-table.md) lists the implementation-grounded reviews. [Lightweight coverage](./lightweight/README.md) records what could be learned from papers, READMEs, or other documents instead.
- The [comparative review](./agentic-memory-systems-comparative-review.md) interprets its 148-system snapshot. The [historical matrix](./systems.csv) is not the current comparison dataset.
- The [original survey overview](https://github.com/zby/commonplace/blob/7721cc141/kb/agent-memory-systems/README.md) preserves the survey method, cross-system observations, open questions, and the citation for the deposited paper corpus.
