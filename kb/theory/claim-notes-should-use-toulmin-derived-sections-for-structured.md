# An assumption worth disputing is worth stating

When writing a note, ask: **Could a reader accept my evidence and still reasonably reject my conclusion?** If so, state the assumption that reader would need to accept. In [Toulmin’s account as presented by Purdue OWL (snapshot required)](../sources/purdue-owl-toulmin-argument.ingest.md), the evidence supplies the *grounds*; the assumption connecting it to the claim is the *warrant*.

Consider this draft: “No other note links to the release checklist, so we can delete it.” The search may be accurate even if the release team opens the checklist from a bookmark every Friday. The argument assumes that a checklist worth keeping would have a link from another note. Stating that assumption exposes what the writer does not yet know. A better note says: “No other note links to the checklist. Before deleting it, ask the release team how they reach it.”

One sentence can make the reasoning explicit. Use separate [Evidence and Reasoning sections](./types/structured-claim.md) when readers need to inspect the observations together and then examine what follows from them. Keep the reasoning beside the evidence when separating them would make readers reconstruct the connection. Some Commonplace notes were returned to ordinary prose for that reason.
