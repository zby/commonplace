# Theory evidence

These notes explain what a particular experiment, set of traces, or comparison shows and where that inference stops. For example, the [write brief experiment](./full-write-briefs-cut-edit-drift-one-line-briefs-did-not.md) compares which requirements survived edits when writers received a full brief, a one-line brief, or no brief. See [evidence placement](../COLLECTION.md#evidence-placement) for the distinction between theory evidence and reports about Commonplace alone.
