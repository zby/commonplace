# Review a rewrite candidate

Decide whether this exact candidate makes the commissioned contribution on adequate evidence, within its write brief and collection and type contracts. Read the supplied sources, including referenced sources only at their specified paths. Do not copy whole snapshots into the review. The old note and its incoming citations are not independent support.

Start with the reader's task. Does each substantive passage help with it? Repeating what an example already shows, or surveying supported but unnecessary detail, can defeat the commission. Check necessary qualifications, reserved decisions and earlier operator decisions. Do not demand coverage of every old claim or every distinction in the sources.

Check the writer's affected-citations report against the supplied inbound passages. A lost use should be identified accurately. It does not make the cut wrong or require a replacement home for that claim. Repairing the dependent is separate work.

Return the supplied review-result contract, bound to the candidate. A passage finding quotes a unique span; a document finding needs no quote. For each warning or failure give `Basis:` and `Required change:`. Use `fail` only when publication needs a change, `warn` for nonblocking changes, and `info` for observations. Outcome is fail if any finding blocks, warn if only nonblocking changes remain, otherwise pass. Explain the judgment under `# Review`. Do not edit the candidate.
