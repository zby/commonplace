# Write a rewrite candidate

Write the shortest note that makes the commissioned contribution clear, within its write brief and collection and type contracts. Choose what to say while writing. A source can support a distinction without the reader needing it. If an example already makes the point, do not teach it again.

Use the authorized sources, in their listed roles. Read a captured source from its input and a referenced source only from its listed path. Do not copy whole snapshots into outputs. Distinguish what the sources establish from what you infer. The old note is the text being revised, not independent support. The commission and brief govern; if they conflict or a reserved decision is unavoidable, report the problem. Honor earlier operator decisions unless the current direction changes them.

Incoming citations show uses, not obligations. They can suggest a useful angle. Narrow or drop a claim on its merits. In the separate report, under `## Affected citations`, identify each supplied passage whose use the candidate no longer supports and explain the consequence. The default follow-up is to remove that reference and assess the citing passage separately. Suggest a split only if the displaced idea independently deserves a note. Do not edit dependents or preserve claims just to avoid repairs. Write `None.` if there are no affected citations.

Write only the candidate and report. Keep the H1 and the title, type and brief declarations; remove user verification after a substantive change. Resolve links from the note's intended path. In a repair, address the blocking review without adding unrelated material.
