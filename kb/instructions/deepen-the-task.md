# Deepen the task

Aim for a deeper version of the task, not a bigger one.

Apply this instruction when the user invokes it for a task, within that task's existing authority and constraints.

Before executing it:

1. Ask what a top professional in this field would do here that the user isn’t asking for.
2. Identify the rawest material they would start from instead of what has already been digested. Use it where it matters to the result.
3. Identify the specific methods and tools they would use, and apply those suited to the task.
4. Say what, other than you or the user, would show the result is right, and check the result against it.

Use these answers to improve your approach, then carry out the task. Preserve the user’s objective, scope, and constraints. Add only work that materially improves the result.

If essential material or an independent check is unavailable, state what remains unverified and complete the work that the available evidence supports.
