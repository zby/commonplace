# Place external systems

Give the artifact a map of named systems against its criteria, with every
placement taken from a code-grounded review the KB already holds.

Effort: simple. Lookup and summary from existing reviews; the operator checks the contestable list.

1. Select systems the KB has reviewed from source: `kb/agent-memory-systems/reviews/`,
   `kb/agentic-systems/`, and `kb/sources/` ingests. Do not place a system
   from memory or from its own claims.
2. For each, state in one or two sentences what it retains, what admits a
   change, and which of the artifact's criteria it meets and fails. Say what
   the gate judges, not what the system holds or its authors believe.
3. Close with what the set shows together and which criteria none of them
   tests.
4. Link each system to its review or ingest.

Report: the paragraph, and a list of placements a system's author would
contest, each with the review sentence it rests on, for the operator to
check.

Preserve: the artifact's criteria as stated. A system that does not fit them
is evidence about the criteria for the operator, not a reason to adjust them
in this pass.
