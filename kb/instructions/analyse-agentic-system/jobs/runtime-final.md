# Write the runtime member

Write the output your prompt names under the [runtime report type](../../../types/agentic-system-runtime-report.md): the runtime draft, `runtime-draft.md`, with what the last reconciliation registered and corrected.

1. Declare every record the reconciliation registered from an `EPI-` proposal, under its canonical ID, with the identity the reconciliation gives and the record fields the type requires. Take its evidence from the epistemic draft's finding and the sources. An `ABS-*` record states its searched boundary: the patterns and the tree or files searched.
2. For each passage the epistemic draft's `## Returns to the coordinator` asks to retain for a record this member declares, generate the quote block with `commonplace-quote` and insert it unchanged beside that record. Each passage occurs once across the set.
3. Apply each `Amendment:` the reconciliation states for a record this member declares: keep the record's referent, and append the entry to the member's `## Amendments` section.
4. Change nothing else in the draft. A record the memory report declares stays in the memory member; do not declare it here.

Your output is refused while any record the reconciliation, the epistemic draft, or the memory member cites is declared nowhere in the set; the refusal names the IDs.
