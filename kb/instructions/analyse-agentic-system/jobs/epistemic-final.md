# Write the epistemic member

Write the output your prompt names under the [epistemic report type](../../../types/agentic-system-epistemic-report.md) from `epistemic-draft.md`. Replace each `EPI-` proposal ID with the canonical ID the reconciliation's epistemic table maps it to, by exact token; remove a proposal the table rejects. Drop the draft's `## Returns to the coordinator` section, and replace each reference to it, such as "see Returns, targeted read 3", with the canonical record that now retains the passage or the correction. Every canonical ID you cite is declared in the round's runtime member or memory member, both among your inputs; your output is refused while one is not. Change nothing else: a finding the reconciliation contradicts goes into a problem report, not into an edit of the finding. The member declares no records and cites only canonical IDs.
