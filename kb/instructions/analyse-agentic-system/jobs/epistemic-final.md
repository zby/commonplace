# Write the epistemic member

Write `output/epistemic.md` under the [epistemic report type](../../../types/agentic-system-epistemic-report.md) from `epistemic-draft.md`. Replace each `EPI-` proposal ID with the canonical ID the reconciliation's epistemic table maps it to, by exact token; remove a proposal the table rejects. Drop the draft's `## Returns to the coordinator` section. Every canonical ID you cite is declared in `output/runtime.md` or the memory member. Change nothing else: a finding the reconciliation contradicts goes into a problem report, not into an edit of the finding. The member declares no records and cites only canonical IDs.
