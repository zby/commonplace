# Superseded: factory construction versus production-knowledge acquisition

This path is retained so existing links do not break. The earlier wording used *specialization* for the acquisition of family-specific production knowledge, but Greenfield already uses **factory specialization** for a particular operation on a factory's viewpoints, artifacts, activities, and assets.

Use [A software factory can produce another factory without acquiring its family-specific production knowledge](./a-software-factory-can-produce-another-factory-without-acquiring-its-family-specific-production-knowledge.md) instead.
