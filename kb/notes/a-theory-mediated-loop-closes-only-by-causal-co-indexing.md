# A theory-mediated loop closes only by causal co-indexing, not by co-occurrence inside one boundary

A system is said to improve through its own theory when one causal path carries four links in order:

1. **Guidance.** The retained theory guides a change to the system's [behavior-determining organization](./definitions/behavior-determining-organization.md).
2. **Test.** The result of that change is read back against that same theory.
3. **Revision.** The theory is revised in response to what the result showed.
4. **Effect.** The revised theory affects later operation on the same path.

Call this **causal co-indexing**: the same theory is the object at every link, and the links lie on one path rather than on four unrelated ones. The index that has to be shared is the theory, and the thing that has to be shared is the path.

Co-indexing is a stronger requirement than the co-occurrence of the three underlying properties. [Theory-mediated learning](./theory-mediated-learning-may-improve-sample-efficiency-under-shifts.md), [reflection](./definitions/reflective-system.md), and [self-improvement](./definitions/self-improving-system.md) are each attributed relative to a declared boundary, and each can be witnessed somewhere inside a boundary without the four links meeting.

## Three disconnected paths are the counterexample

Consider one system with three separate paths.

- On the first, a retained design theory guides how a component is written. Nothing reads the component's later results back against the theory, so the theory is guidance that is never tested.
- On the second, a metric-gated loop revises rules or skills the theory does not touch. Evidence reaches an admission gate and installed changes affect later operation, so the loop is reflective and self-improving — and it revises artifacts that no retained theory derives.
- On the third, a review process revises the theory from reading and criticism. The revised theory governs no change, so revision affects nothing downstream.

Each of the three properties is present inside the declared boundary. Theory mediation appears on path one, a closed improvement loop on path two, theory revision on path three. Yet no theory here is both guiding and revised by what its guidance produced. Aggregating the three witnesses into "this system improves through its theory" attributes to the system a loop that none of its paths contains. Co-occurrence is satisfied and co-indexing fails, so co-occurrence does not entail co-indexing.

## The test is stated over a named path

Because the counterexample turns on which path each witness sits on, the test has to name the path before it checks anything: identify one theory and one operative path, then show links 1 through 4 on that path with that theory.

Showing the links takes more than reconstructing them from the architecture. Links 1 and 4 are causal claims about particular episodes, and an evidence protocol closes them in one of two ways. A **mediation trace** records that the theory was consumed where the change was decided — the citation at the decision point, or a retained record of the artifact being read there — which is what makes the trace cheap in an addressable system and expensive without one ([reflection buys addressability](./reflection-buys-addressability.md); an observed instance is the [tag-README trace](./evidence/tag-readme-trace-observed-causal-connection.md)). Alternatively an **intervention** varies the theory — withheld, pinned to an earlier version, replaced — and observes whether the change differs, which identifies exactly the contrast it runs and no finer ([an experiment identifies only the contrast it actually runs](./an-experiment-identifies-only-the-contrast-it-actually-runs.md)). This note claims only that one of the two is needed; what a trace has to record to count is a separate question.

## Why co-occurrence is the tempting substitute

Two things make the weaker reading attractive.

Boundary-relative attributions are cheap. All three properties are assessed against a declared boundary, and [the boundary is a declaration rather than a fact about the system](./the-self-improving-system-definition-classifies-its-boundary-cases.md). Widening the boundary adds witnesses without adding paths, so a system can acquire the third property by redrawing its edge — and the aggregate claim reads as if something inside had changed.

The three tests already in use each check one link and stop. An occurrence test asks whether an evidence-responsive operative change happened at all, which is link 1 without the theory's identity attached. A revision-surface test asks whether the change class stays open to further revision, which bears on link 4 and says nothing about what guided the change ([a repeatable operative path keeps a redesign class open to revision](./a-repeatable-operative-path-keeps-a-redesign-class-open-to-revision.md)). A compounding test asks whether an earlier retained change helped produce a later improvement, and its causal-trace requirement is close to what links 1 and 4 need — but it tracks a retained *change*, not the identity of a retained *theory* across guidance and revision ([compounding is tested in later improvement](./compounding-is-tested-in-later-improvement-not-by-the-accepting-metric.md)). Each is a good test of its own question. Running all three still leaves the chain unchecked, because none of them asks whether the same theory occupies both ends.

The case-wise application already exists: [three 2026 harnesses retain rules or weights rather than a revisable theory](./evidence/three-2026-harnesses-retain-rules-or-weights-not-a-revisable-theory.md) reads two systems as having links 1 through 4 present in fragments with no retained object shared between them. This note states the criterion those readings apply.

## Scope

- This is a condition on the attribution *this system improves through its theory*, not on *self-improving* in general. A system with no theory at all can satisfy the [self-improving-system definition](./definitions/self-improving-system.md); it simply is not a case this criterion is about.
- The condition is necessary, not sufficient. Co-indexing does not show that the revision made the theory better, that the loop compounds, or that the interpretation at link 2 was competent — [membership, interpretation, and separable retention are separate requirements](./theory-mediated-self-improvement-needs-interpretation-and-retention.md).
- The attribution is path-relative and theory-relative. A system may close the loop for one theory on one path and fail for others, so satisfying the test licenses a claim about that path rather than about the system.
- Nothing here says how common closed loops are, or that a system failing the test is worse than one passing it.
- The claim assumes that a revised theory can be identified as the successor of the theory that guided the change. Where revision replaces a theory wholesale rather than rescoping it, link 3 may break the identity the other links depend on, and the criterion has no answer yet for that case.

## Open Questions

- What minimal intervention distinguishes co-indexing from coincidental co-occurrence in a live system, given that withholding a retained theory changes the operating context as well as the guidance.
- Whether the theory-identity condition can be stated sharply enough to survive wholesale replacement, or whether replacement should count as ending one loop and starting another.
- Whether a path with three of the four links deserves a named weaker attribution, or whether partial chains are better reported as the links they close.
