# Methodology

How an agent comes to work by a method: which of many known approaches it selects, how an external methodology becomes operative in it, how a stated intent controls its local choices, and how far a method transfers between problems. The notes here are about methodology as a thing an agent holds and applies. What a methodology is relative to a theory, and how the two execute together, lives under [learning-theory](./learning-theory-README.md).

## Selection and borrowing

- [A capable agent needs methodology selection, not just relevant knowledge](./capable-agents-need-methodology-selection.md) — a capable agent knows many individually relevant but mutually incompatible approaches, so task control requires choosing one
- [Borrowing can operate through retained artifacts or weight activation](./borrowing-can-operate-through-retained-artifacts-or-weight-activation.md) — an external methodology becomes operative either by being retained in the system or by being activated in the model
- [Weight-resident methodologies provide context-efficient behavioral compression](./weight-resident-methodologies-compress-behavior-in-context.md) — a compact cue activates a much larger methodology the weights already hold, at low context cost and with less inspectability

## Control and transfer

- [Intent controls a local choice only when it distinguishes its live alternatives](./intent-controls-choices-by-distinguishing-live-alternatives.md) — a stated intent controls a choice only when it changes which live alternatives are admissible or preferred
- [Problem matches guide method search; mechanism matches bound transfer](./problem-matches-guide-method-search-mechanism-matches-bound-transfer.md) — a problem match generates candidate source methods; a mechanism match is what bounds whether the method transfers
- [Decorrelated reviewers still share the field's prior, so read their findings by the claim's stance](./reviewers-share-the-fields-prior-so-interpret-findings-by-stance.md) — a review methodology's blind spot: reviewers converge on consensus where a claim is original, so findings are read by the claim's stance
