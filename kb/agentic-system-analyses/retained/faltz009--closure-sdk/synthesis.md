# Closure-SDK synthesis

## Bounded synthesis

### A numerical memory subsystem, not an agent harness

Closure EA's strongest supported contribution is an implemented chain from accumulated observations and target feedback to changed numerical memory and later consumers. It can revise values, reorganize entries and use the resulting state on subsequent calls. Whether those changes improve future performance remains unestablished. The analysis covers the current Rust Closure EA subsystem within Closure-SDK at commit `9735f48a6ddd00b6f429a91443489531b3a115ef`, with applicability cutoff 2026-10-13. SRC-1 supplies inspected implementation and attributed design, not observed execution or causal experiments. No target tests or examples were run. The sibling integrity SDK, geometric database, archived Python runtime, homeostasis demo and browser implementation are excluded; this is not a whole-monorepo assessment ([boundary](boundary.md#boundary-and-evidence), [Source register](boundary.md#source-register)).

The runtime is synchronous local Rust computation. A caller supplies quaternion carriers—four-component numerical inputs—and, for teaching, expected targets. `ThreeCell` owns field reads, buffer aging, closure processing, corrective writes and maintenance. The caller owns scheduling, labels and save/load timing. Fixed symbolic rules operate over mutable dense geometry; there is no model-provider endpoint in these traced loops. Source terms such as “brain” and “semantic” do not establish human-like cognition or an LLM integration ([RT-CMP-three-cell](runtime.md#rt-cmp-three-cell), [RT-RTE-carrier-ingest](runtime.md#rt-rte-carrier-ingest)).

### From input to retained field

Ingestion puts a carrier into a live buffer, advances ages, computes error and chooses a channel from input geometry. ZREAD composes values from eligible genome and buffer entries; RESONATE finds a closest address. These are numerical selection operations, not construction of a text prompt. Retained addresses select entries, while their values determine returned content; the two can diverge. LOAD provides a genome reference for geometric verification. Genome hits use their exact index; buffer hits instead use a genome nearest-address fallback. Surprise and non-self Identity or Balance verification can tag observations for later retention ([RT-RTE-carrier-ingest](runtime.md#rt-rte-carrier-ingest), [EPI-RTE-verify-check](epistemic.md#epi-rte-verify-check), [memory annotations](memory.md#annotations)).

Expired tagged buffer entries enter the genome; untagged entries are discarded. This gate is local, not a global requirement that every retained input passed independent validation. Supported structural products, higher-level closure packets, target associations, direct seeding, public mutable access and state reconstruction provide other admission paths. A Carry event can cascade into a higher level and write there directly; FixedPoint does not initiate that cascade ([MEM-OBJ-buffer](memory.md#mem-obj-buffer), [MEM-RTE-hierarchy-retention](memory.md#mem-rte-hierarchy-retention), [RT-RTE-direct-maintenance](runtime.md#rt-rte-direct-maintenance), [RT-RTE-state-restoration](runtime.md#rt-rte-state-restoration)).

The field separates DNA structural entries, Epigenetic event/closure entries and Response context/target associations. Layer-sensitive methods protect DNA values from certain corrections and omit DNA from merge/prune. That is a local update protocol, not immutable storage: mutable references and reconstructed state can bypass it. Later requested computations read retained geometry, and generation follows highest-count stored edges. Buffer lifetime is measured in explicit ticks. No token budget or model-visible context window is established; closure processing removes resolved history windows while retaining unresolved prefixes and derived products, not lossless pointers to discarded inputs ([MEM-OBJ-dna](memory.md#mem-obj-dna), [MEM-OBJ-epigenetic](memory.md#mem-obj-epigenetic), [MEM-OBJ-response](memory.md#mem-obj-response), [MEM-OBJ-closure-histories](memory.md#mem-obj-closure-histories), [RT-RTE-readonly-consumption](runtime.md#rt-rte-readonly-consumption)).

### Feedback changes organization without authenticating targets

A teaching caller commits a prediction into one replaceable pending slot, then supplies a target. Evaluation consumes that slot, calculates a geometric discrepancy and a threshold-based `correct` flag, credits eligible Response entries, writes the captured context/target association and changes sequential edges. Incorrect predictions can weaken an edge; discrepancy contributes maintenance pressure. Both correct and incorrect results proceed through association writing. The target is the caller's answer oracle, not independently authenticated reality ([RT-OBJ-pending-prediction](runtime.md#rt-obj-pending-prediction), [RT-RTE-prediction-feedback](runtime.md#rt-rte-prediction-feedback), [EPI-RTE-feedback-check](epistemic.md#epi-rte-feedback-check), [EPI-RTE-response-write](epistemic.md#epi-rte-response-write)).

Correct-credit attribution is narrower than update capacity. Teaching callers can label a buffer hit's index as a genome slot. Eligibility comes from Cell C, without establishing that it produced an arbitrary committed prediction. Maintenance remaps genome references but not pending indices. These problems prevent stable producer/slot guarantees; they do not erase the separate context/target write and its later consumers ([report-verification limits](report-verification.md#limits)).

Queries, commits and corrections also accumulate coupling, coalition, salience and coherence statistics. Maintenance consumes these traces to merge, prune and promote memory. Same-channel statistics include entries below ZREAD's value-contribution cutoff, so they are not solely a record of actual selected-value participants. Consolidation combines eligible same-layer entries and removes selected weak mutable entries, with a configurable coalition-survival exception for Response entries. When the coalition gate is enabled, eligible Response merge proposals prioritize co-resonance rather than universally nearest addresses. Force bypasses pressure, not all internal selection criteria ([MEM-OBJ-genome-statistics](memory.md#mem-obj-genome-statistics), [MEM-RTE-memory-consolidation](memory.md#mem-rte-memory-consolidation), [report-verification limits](report-verification.md#limits)).

Promotion uses recurrence, salience, coupling, coalition and conditionally sufficiently sampled coherence, then checks higher-level novelty. Promoted values enter level-1 storage and explicit level-read capabilities; an automatic path back into primary level-0 prediction is not established. The promoted write retains selected support metadata, not the full episode or reasons for promotion. These are operational eligibility and organization changes, not acceptance and subsequent integration of a new explanatory proposition ([EPI-RTE-category-check](epistemic.md#epi-rte-category-check), [EPI-RTE-category-disposition](epistemic.md#epi-rte-category-disposition), [MEM-RTE-memory-consolidation](memory.md#mem-rte-memory-consolidation)).

### Later use, checkpoints and local warrants

`evaluate` composes a requested sequence and selects over genome plus live buffer without the ingestion channel restriction. `generate` starts from a genome seed and follows stored edges. Associative recall and OrbitRuntime are shipped consumers, not hypothetical storage clients. Numerical state therefore has a concrete channel to later outputs; exercised dependence and benefit remain unobserved ([RT-RTE-readonly-consumption](runtime.md#rt-rte-readonly-consumption), [RT-BAP-field-consumption](runtime.md#rt-bap-field-consumption)).

Persistence has separate contracts. BrainState saves genomes, selected histories, buffer, pressure and pending feedback, but restoration resets neuromodulation and transient self-observation/salience. Genome-only reconstruction affords resumed training with fresh transient state and no restored higher-level runtime organization. Vocabulary is saved separately. Temporary-file rename provides best-effort replacement, not demonstrated crash durability, migration or automatic rollback. None of these capabilities establishes a shipped cross-process reuse sequence or equivalence to uninterrupted execution ([MEM-OBJ-brain-state](memory.md#mem-obj-brain-state), [RT-RTE-state-restoration](runtime.md#rt-rte-state-restoration), [MEM-RTE-genome-reconstruction](memory.md#mem-rte-genome-reconstruction), [MEM-OBJ-vocabulary](memory.md#mem-obj-vocabulary)).

Local evaluators exist, but their licenses differ. VERIFY establishes geometric closure within tolerance. Feedback establishes agreement with supplied targets. Accuracy code scores selected examples without enforcing held-out independence or automatically admitting a claim. The solver checks nearest-slot identity, not exact equation equality. Integer factor outputs have a conditional arithmetic witness license, while enumeration-based labels do not establish properties recovered from learned carrier content. Arbitrary carriers do not by themselves individuate external propositions. Token normalization and hash-derived addressing likewise do not establish unrestricted semantic preservation; nearest decoding lacks a semantic confidence veto. These findings neither validate nor refute the source's unassessed theorem and prime-zero correspondence claims ([EPI-RTE-accuracy-report](epistemic.md#epi-rte-accuracy-report), [EPI-RTE-slot-solver](epistemic.md#epi-rte-slot-solver), [EPI-RTE-factor-output](epistemic.md#epi-rte-factor-output), [EPI-RTE-vocabulary-codec](epistemic.md#epi-rte-vocabulary-codec), [EPI-CLM-closure-convergence](epistemic.md#epi-clm-closure-convergence), [EPI-CLM-prime-zeros](epistemic.md#epi-clm-prime-zeros)).

### What the representative workflow establishes

The shipped neuromodulation experiment connects these operations in one bounded caller. Two independent configured brains receive stable or disrupted contexts for 20 rounds, each with eight context inputs before a pattern. Each round immediately commits and evaluates against a fixed label. Final forced consolidation follows copying the body tones. Returned tuples therefore mix pre-final-maintenance tones with promotion counts including final maintenance. The example prints comparisons and asserts disrupted arousal is higher and coherence lower before its final verified message. Those checks concern tone ordering, not recall accuracy or successful learning. Failure supplies no internal retry or rollback, and the example invokes no persistence. This is synchronous numerical experimentation, not established worker delegation or multi-agent delivery ([WF-RTE-regime-comparison](workflow.md#wf-rte-regime-comparison)).

For the scenario actually supported—caller-led numerical association, corrective feedback and subsequent field reads—the implementation supplies automatic retained updates and real later consumers. For semantic knowledge production, promoted-category improvement of primary recall, or dependable cross-session continuity, the evidence does not establish the corresponding guarantees. Trace-fed adaptation is wired; improved capacity for future action is not demonstrated. No accepted member establishes that criticism of a consumed formulated theory improved future capacity. The runtime supplies no separate supported assessment of theory-builder conditions 1–4, so this synthesis assigns no system-wide result to those conditions. The represented self-discrepancy and body-state mechanisms are insufficient here for a complete reflection finding; synchronous internal computation likewise does not establish an autonomous theory builder. These are independent unresolved properties, not implications of missing performance evidence ([RT-RTE-prediction-feedback](runtime.md#rt-rte-prediction-feedback), [epistemic conclusion](epistemic.md#bounded-conclusion), [profile verification](profile-verification.md#verification)).

Feedback and trace-conditioned maintenance provide an improvement-directed self-change pathway: discrepancy/statistics shape updates to the runtime's own field, and that field has later behavioral force. This supports a dispositional pathway, not exercised self-improvement: no supplied subsequent operation establishes causal dependence on the change, and no outcome establishes successful improvement. The source's convergence claims remain design assertions beyond that contribution ([RT-CLM-teaching-convergence](runtime.md#rt-clm-teaching-convergence), [MEM-RTE-memory-consolidation](memory.md#mem-rte-memory-consolidation), [RT-BAP-field-consumption](runtime.md#rt-bap-field-consumption)).

An inspectable before/after run with linked updates and later outputs would strengthen the exercised-dependence finding. Controlled comparisons independently varying correction or consolidation would be needed for component benefit, rather than attributing a whole episode's outcome to one mechanism. Preserving population identity and remapping pending references would change the credit-fidelity assessment. Identifying a shipped promoted-state consumer would change the integration assessment; paired checkpoints and continuation comparisons would change the continuity assessment. Semantic claims require explicit carrier interpretation and evidence-consuming acceptance within a named scope, while theorem claims require audited correspondence to executable prerequisites. No new source reads were made for this synthesis.
