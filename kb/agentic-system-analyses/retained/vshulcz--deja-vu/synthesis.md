# deja-vu synthesis

## Bounded synthesis

### From prior work to retained state

deja-vu is a cross-agent memory and context-delivery system, not the enclosing agent runtime. This account concerns `https://github.com/vshulcz/deja-vu` at commit `4c08fb26ad8a8b8e656a120f06ca4175a7078148`, with an analysis cutoff of 2026-10-14. SRC-1 supplies executable source, shipped instructions and attributed historical reports. No target code, tests, hosts or providers were executed, and no independent run trace or causal experiment was supplied. The whole-system functional boundary includes shipped consumers, writers, maintenance paths and evaluators; it does not mean every variant was inspected. External hosts own inference, original transcript production, tool execution and actual instruction loading ([boundary](boundary.md#boundary-and-evidence), [Source register](boundary.md#source-register)).

The claimed work is to recover prior fixes and decisions, supply relevant history before action, retain settled decisions and continue after compaction. The shipped skill requests searching before editing and before declaring completion. Its priority rule is a request to the model, not an enforced prerequisite for action ([RT-CLM-search-before-edit](runtime.md#rt-clm-search-before-edit)).

Host transcripts, caller-written notes and imported batches feed a local filesystem index. Normalization, self-recall stripping, redaction and clipping produce derivative text, not a complete original transcript. Explicit notes persist separately in JSONL and reload into search. Promoted decisions append revisions with source and lifecycle fields; imported lifecycle summaries have a separate metadata read path. A generic CLI or MCP caller does not establish human authorship or per-content approval. Structural admission makes content storable, not true ([RT-OBJ-index-db](runtime.md#rt-obj-index-db), [MEM-OBJ-records](memory.md#mem-obj-records), [MEM-OBJ-notes](memory.md#mem-obj-notes), [MEM-OBJ-session-meta](memory.md#mem-obj-session-meta), [RT-RTE-note-admission](runtime.md#rt-rte-note-admission), [RT-RTE-import-records](runtime.md#rt-rte-import-records)).

The retained corpus also feeds automatic derivatives: error/remedy associations, recurring commands and failures, token associations and bounded session-outcome summaries. These mix interpreted text with symbolic keys, counts and flags. Optional embeddings produce retained dense numerical representations through a configurable, unpinned endpoint. Local sidecar storage does not establish a vector database, stable provider weights or absence of provider retention ([MEM-RTE-trace-mining](memory.md#mem-rte-trace-mining), [MEM-OBJ-cooccur](memory.md#mem-obj-cooccur), [MEM-OBJ-commands](memory.md#mem-obj-commands), [MEM-OBJ-commandfails](memory.md#mem-obj-commandfails), [MEM-OBJ-sessionfacts](memory.md#mem-obj-sessionfacts), [RT-CMP-embed-client](runtime.md#rt-cmp-embed-client)).

### From retained state to the next action opportunity

Consumers can request recall through CLI or MCP queries and session identifiers. Separately, startup, prompt, file, error, plan and supported spawn events trigger automatic selection. Code selects by project, task overlap, lexical relevance, recency, origin policy, lineage exclusions, novelty and budgets. The inspected pi extension turns binary output into a hidden model-facing message or appended tool-result text. The host owns the next inference; deja does not execute a recalled repair. Child-prompt rewriting is a separate route, not inheritance of the parent's whole context or a grant of child tools ([RT-RTE-requested-recall](runtime.md#rt-rte-requested-recall), [RT-RTE-auto-delivery](runtime.md#rt-rte-auto-delivery), [RT-RTE-spawn-context](runtime.md#rt-rte-spawn-context)).

These channels have different controls. Automatic, MCP and shell-search origin grants are independent, so denying automatic delivery does not deny shell access. Matching expired startup caches can be served while refresh runs; the cache gate does not encode the entire policy file. The pi extension treats subprocess errors and timeouts as missing memory rather than intentionally aborting the agent turn. Framed agent-facing history requests treatment as untrusted reference data; human-facing CLI text offers an unframed alternative. None of these controls supplies a host action sandbox ([RT-OBJ-policy](runtime.md#rt-obj-policy), [RT-RTE-auto-delivery](runtime.md#rt-rte-auto-delivery), [RT-RTE-requested-recall](runtime.md#rt-rte-requested-recall), [RT-BAP-recall-reference](runtime.md#rt-bap-recall-reference)).

Accepted project decisions are supplied at startup without a topical query. The selector reads latest local marks or imported accepted metadata, then orders, deduplicates and reduces them within six-note/800-byte limits. Here `accepted` records a caller's lifecycle choice, not an independent evidence-consuming truth decision. An after-write overlap warning neither establishes contradiction nor rejects admission. First-sentence reduction can remove a necessary condition: the epistemic account's implementation deduction turns `Use pgx. Only in service A.` into `Use pgx.`. That example changes directive scope; it does not establish a category of factual inference. Factual reminder preservation remains indeterminate without comparing the actual propositions. Imperative reminders also cross a frame that says not to follow instructions inside history. Effective priority depends on model interpretation, which was not observed ([MEM-RTE-convention-delivery](memory.md#mem-rte-convention-delivery), [EPI-OBJ-lifecycle](epistemic.md#epi-obj-lifecycle), [EPI-RTE-conflict-check](epistemic.md#epi-rte-conflict-check), [epistemic authority ledger](epistemic.md#authority-route-ledger), [report verification](report-verification.md#verification)).

### Checks that change selection, not guarantees of repair

Production fix mining has consequential checks. It pairs recognized errors with nearby eligible commands and rejects detected failures or later matching error recurrence; a separate edited-file fallback is weaker. Missing exit status or nearby output can pass the command failure detectors. Judgment then uses repaired/substitute features, term sharing or eligible repetition to distinguish confirmed associations from candidates. This is evidence-consuming disposition for historical remedy selection, not causal acceptance that a command repaired the project ([EPI-RTE-fix-check](epistemic.md#epi-rte-fix-check), [EPI-RTE-fix-disposition](epistemic.md#epi-rte-fix-disposition)).

Per-session pre-judgment evidence persists so new or changed records can alter later judgments. Confirmed associations are preferred, but requested fix lookup can return labelled unconfirmed candidates when none survives. Plan remedy selection refuses candidates. Thus there is no system-wide never-served candidate gate. Plan checks separately count related recurring historical walls and deliver advisory context; they do not deny plan submission. Silence can mean unavailable state, filtering, deduplication or no match, not plan safety ([MEM-OBJ-fixraw](memory.md#mem-obj-fixraw), [MEM-OBJ-fixes](memory.md#mem-obj-fixes), [EPI-RTE-fix-retention](epistemic.md#epi-rte-fix-retention), [EPI-RTE-fix-selection](epistemic.md#epi-rte-fix-selection), [EPI-RTE-plan-check](epistemic.md#epi-rte-plan-check), [EPI-RTE-plan-delivery](epistemic.md#epi-rte-plan-delivery)).

### Continuing and changing standing guidance

Compaction capture automatically extracts goals, constraints, conclusions, commands/outcomes and carry material into non-searchable retained state. Previous carry and rules can feed recapture. The host chooses what leaves its context; deja keeps bounded copied text, not a live reference to the removed window. Exact session/workspace selection, privacy checks, failure/delivery tokens and repository fingerprints govern later recovery. The recovery packet is limited to 4 KiB. Changed repository state prompts revalidation warnings rather than proof of continued validity. Full successful stdout write precedes marking this emitter's packet delivered, but does not prove host receipt, and deferred queues have a different destructive-take boundary. An additional capture heuristic can label output with no detected friction as `passed`; undetected failure remains compatible with that premise ([MEM-OBJ-compaction-data](memory.md#mem-obj-compaction-data), [MEM-OBJ-compaction-state](memory.md#mem-obj-compaction-state), [RT-RTE-compaction-recovery](runtime.md#rt-rte-compaction-recovery), [epistemic authority ledger](epistemic.md#authority-route-ledger), [report limits](report-verification.md#limits)).

The representative multi-step workflow turns prior corrections into standing rules. The foreground agent requests candidates from the binary, interprets recurring preferences, proposes at most 15 rules with support from at least two sessions, stops for user selection, appends chosen lines and invokes distribution. Extraction and copying are implemented; interpretation, stopping and approval are prescribed host behavior. Candidate clipping and text-prefix deduplication reduce the evidence available for session-count judgments. Sync checks source size and delimiters, then writes marked blocks to known ready targets. It can partly succeed before reporting a target refusal. The user or foreground agent repairs the named file and retries; changing or emptying the source and resyncing reverses bounded copies. File-level delivery is not proof of later loading or compliance ([workflow account](workflow.md#workflow-account), [RT-RTE-rules-sync](runtime.md#rt-rte-rules-sync), [RT-BAP-standing-rules](runtime.md#rt-bap-standing-rules)).

Other recovery is likewise bounded: handoff supplies a digest, native write-back recreates conversation without the original tool calls/output, and restore supplies a recorded span rather than a complete file. Forgetting persists local suppression before rebuild, but source withdrawal, deletion of authored decision text and revocation of exported copies are different operations ([MEM-RTE-session-recovery](memory.md#mem-rte-session-recovery), [MEM-RTE-forget-cleanup](memory.md#mem-rte-forget-cleanup)).

### Assessment at this boundary

The strongest supported contribution is implemented automatic conversion of accumulated experience into durable suggestions and continuation context with later consumers. Retained raw sightings can change future remedy disposition; retained continuation material can shape recapture and later model input. This establishes wired trace-fed update paths, not improved capacity for future action. Whether those changes help subsequent work remains unresolved. Default promoted-note distillation is another qualifying path, omitted from the profile's explicitly partial trace inventories; its omission does not invalidate their existing positive findings ([MEM-RTE-trace-mining](memory.md#mem-rte-trace-mining), [EPI-RTE-fix-retention](epistemic.md#epi-rte-fix-retention), [MEM-OBJ-compaction-data](memory.md#mem-obj-compaction-data), [EPI-RTE-promote-distill](epistemic.md#epi-rte-promote-distill), [profile limits](profile-verification.md#limits)).

No supplied route establishes that criticism of a consumed theory improved later capacity. Theory-builder conditions remain independent: condition 1 is unresolved for actual user-rule theory content; condition 2 is not established by delivery alone; condition 3 is not established by feature checks or lifecycle marks as content-directed theory criticism; condition 4 is not established by keeping receipts or recomputing flags as iterative criticism. The runtime does not establish a theory-builder classification. These are withheld conclusions, not system-complete absences. Likewise, reflection is not established as a two-way self-representation mechanism, and autonomous theory building is not established by automatic extraction. The selected rules workflow explicitly assigns a decision to the user. Missing run evidence prevents an exercised self-improvement finding: subsequent operation causally depending on the changed organization is unestablished. Durable selector changes are a supported partial pathway, not proof of successful improvement ([RT-RTE-rules-sync](runtime.md#rt-rte-rules-sync), [MEM-RTE-trace-mining](memory.md#mem-rte-trace-mining), [epistemic bounded conclusion](epistemic.md#bounded-conclusion)).

For recurring coding errors, the evidence supports historical associations and consumer-specific confidence gates, not replay safety or repair attribution. For compaction, it supports bounded reachable continuation, not full window restoration. For recurring preferences, it supports evidence extraction and instruction-file distribution under a prescribed human decision, not enforcement of consent or behavior. The offline evaluators do not settle these questions: gold-session retrieval membership, warning counts and literal coverage measure different targets, and no inspected score path automatically admits production changes ([RT-RTE-retrieval-evaluation](runtime.md#rt-rte-retrieval-evaluation), [EPI-RTE-offline-scores](epistemic.md#epi-rte-offline-scores)).

Evidence that would change this assessment includes linked capture/delivery/model-action traces, before-and-after later-task outcomes with a justified comparison, and independent variation of a claimed component for component attribution. A source change requiring actual outcome evidence before emitting `passed`, preserving reminder conditions, enforcing approval at rule admission, or retaining queued output until acknowledged would alter the corresponding architectural assessment; effectiveness would still need evidence of operation. Further inspection could complete particular variant inventories without turning them into observed benefit. No target source was reread for this synthesis.
