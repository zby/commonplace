# Tortoise synthesis

## Bounded synthesis

Tortoise implements a memory service whose model-dependent write path turns conversational traces into retained graph content, while code selects prior material for later agent context. It is not the enclosing agent's task scheduler. This account concerns SRC-1, `https://github.com/daniel-ospina/tortoise`, at commit `54922a800f96858935b58ef250da569a4896df44`, with an analysis cutoff of 2026-10-30. The evidence is inspected implementation and target-authored design, not an observed execution or causal experiment. The boundary is **complete artifact, partial loop**: the repository is frozen, but selected paths rather than every shipped writer, maintainer and consumer were traced. External host, provider and database internals and live deployments are outside the evidence ([boundary and evidence](boundary.md#boundary-and-evidence), [Source register](boundary.md#source-register)).

### From conversation to retained memory

The shipped entry points offer stdio MCP and HTTP service modes, alongside an in-process SDK. Their admission controls are not interchangeable. In the selected SDK workflow, a caller supplies turns and optionally a session ID. Code validates the request, stores bounded/redacted session turns, and then chooses extraction. Missing provider credentials can therefore leave searchable episodic material without derived memories. Hosted REST and hosted MCP add recording policy, capacity and quota gates; these do not govern every local SDK or direct graph write. The separate production-commit door checks consent before dispatch, but its complete remote consumer remains untraced ([RT-RTE-session-capture](runtime.md#rt-rte-session-capture), [RT-RTE-hosted-capture](runtime.md#rt-rte-hosted-capture), [RT-RTE-production-commit](runtime.md#rt-rte-production-commit)).

Fresh v2 extraction proceeds through chunk narratives, candidate mapping, eligible graph search, gap review and payload construction. The model proposes content; SDK code owns graph effects. Gap review sees the story, current candidates, rendered graph priors and available source transcript. Its default request is for additions and corrections. Code preserves omitted baseline candidates and gives review output precedence on identity collisions. A failed review keeps the baseline with diagnostics; partial output can still merge. Chunk failures and completeness warnings can also permit continuation. This is bounded recovery, not proof that missing information was recovered or every candidate checked true ([WF-RTE-gap-review](workflow.md#wf-rte-gap-review), [workflow account](workflow.md#workflow-account)).

Raw stored turns, transient payloads and admitted graph products are separate milestones. The retained state mixes prose, symbolic IDs/relations/status and numerical representations. Dense embeddings differ from fixed-rule confidence fields and from encoder weights. The local embedding model has a pinned revision; the extraction model's configured alias does not pin exact remote weights. Neither route establishes provider-side training or weight changes ([MEM-OBJ-session-turns](memory.md#mem-obj-session-turns), [MEM-OBJ-derived-points](memory.md#mem-obj-derived-points), [EPI-OBJ-extracted-points](epistemic.md#epi-obj-extracted-points), [RT-CMP-embedding-model](runtime.md#rt-cmp-embedding-model), [RT-CMP-extraction-model](runtime.md#rt-cmp-extraction-model)).

Storage is not one atomic transaction. Graph events, configured JSONL journals and optional Postgres record writes have separate outcomes. A receipt with diagnostics is not a guarantee of complete durable admission. Conditional retry does not roll back earlier writes, and replay of a successful extraction need not heal nonfatal provenance gaps. Direct Point creation and caller-composed checkpoints/diaries are additional admission doors; their shape, namespace and duplicate checks do not establish human endorsement or factual correctness ([RT-OBJ-event-emission](runtime.md#rt-obj-event-emission), [RT-RTE-session-capture](runtime.md#rt-rte-session-capture), [RT-RTE-direct-point](runtime.md#rt-rte-direct-point), [MEM-RTE-checkpoint-diary](memory.md#mem-rte-checkpoint-diary)).

### What checks license—and what they do not

Tortoise's declared evidence architecture is narrower in implementation than the universal claim that every Point keeps a quoted source span. The inspected address check can establish textual occurrence and a value-bearing location in a resolved turn. Missing spans can instead produce warnings while content survives. Occurrence neither proves source truth nor entails the extracted claim. Optional VET likewise judges payload suitability: mechanical identifier-only filtering and optional arbiter opinions can affect membership, but dependency repair can retain or restore referenced entities. A DISCARD token is not an unconditional removal guarantee ([EPI-CLM-evidence-authority](epistemic.md#epi-clm-evidence-authority), [EPI-RTE-source-address](epistemic.md#epi-rte-source-address), [EPI-RTE-vet-check](epistemic.md#epi-rte-vet-check), [EPI-RTE-vet-disposition](epistemic.md#epi-rte-vet-disposition)).

Evidence Propagation computes numerical belief state and makes it consequential for selection. Arithmetic is conditional on stored parameters and graph inputs, not an independently calibrated probability of truth. A declared prior alone can clear volunteering's default 0.7 confidence floor. Dream maintenance can retain recomputed confidence even without convergence; freshness stamping additionally requires convergence, and stale epochs can suppress writes ([EPI-CLM-belief-propagation](epistemic.md#epi-clm-belief-propagation), [EPI-RTE-belief-evaluate](epistemic.md#epi-rte-belief-evaluate), [EPI-RTE-belief-retain](epistemic.md#epi-rte-belief-retain), [MEM-RTE-dream-writeback](memory.md#mem-rte-dream-writeback)).

Correction review is a separate reliance-changing mechanism. Default operation queues candidates. An opt-in automatic branch accepts at a configurable EP mean threshold, default 0.75, subject to promotion eligibility. Measurement is disclosed but is not itself a hard gate: lowering the threshold can admit an unmeasured neutral value. Explicit keep/reject/close decisions have no enforced evidence-consuming criterion and do not identify a human merely by being caller-supplied. Keep can promote and wire prior relationships or supersession; rejection can retract an already-live candidate. These are operative graph changes, but integration and cleanup can partially fail. Their scope is graph-relative correction admission, not independent truth certification ([EPI-RTE-review-disposition](epistemic.md#epi-rte-review-disposition), [EPI-RTE-review-integration](epistemic.md#epi-rte-review-integration), [MEM-RTE-point-retraction](memory.md#mem-rte-point-retraction)).

### From retained state to later model work

The representative end-to-end path needs a later caller sharing the memory state; capture does not schedule another agent task. A framework callback sends a filtered recent window to the reflex. Code selects retrieval intent, searches a bounded pool, reads confidence, filters/sorts candidates, suppresses prior mentions and caps output. The canonical pipeline defaults to three pointers, permits at most five, truncates synopses to 160 characters and caps the block at 8 KiB. Search-matching internals remain unresolved in the accepted records; these gates do not establish a particular lexical or embedding selector ([RT-RTE-context-delivery](runtime.md#rt-rte-context-delivery), [memory annotation](memory.md#on-rt-rte-context-delivery)).

Framework adapters consume the block, not the full structured justification. They append ADK instructions or a user-content fallback, return a LangGraph message, or prepend Semantic Kernel's rendered prompt. Compatible prompt hooks offer another delivery seam. The text asks the agent to follow pointers before settling details, but that is advice, not an enforced evidence-reading step. Whitespace sanitation does not establish resistance to malicious stored prose. The host owns the subsequent model invocation and task actions; delivered context does not prove reliance or benefit ([RT-BAP-framework-block](runtime.md#rt-bap-framework-block), [MEM-RTE-hook-volunteer](memory.md#mem-rte-hook-volunteer)).

Other readers have different semantics. Session-start delivery supplies recency-based excerpts, not task-targeted matches; the inspected local digest lacks canonical terminal-status exclusion. Retraction is therefore not universal withdrawal from future contexts. A shipped evaluation driver expands retrieval pools through source-session traversal, but graph-only expansion does not establish completeness for record-capable turn storage, final reader use or live reflex integration ([MEM-RTE-start-digest](memory.md#mem-rte-start-digest), [MEM-BAP-start-digest](memory.md#mem-bap-start-digest), [MEM-RTE-source-expansion](memory.md#mem-rte-source-expansion), [MEM-OBJ-session-turns](memory.md#mem-obj-session-turns)).

These controls select and shorten the reflex's inputs and add external memory to host work; they do not evict the host's original conversation or establish host-wide compaction. Pointers require explicit retrieval rather than automatic dereference. Retrieval failures can yield unobtrusive silence, but invalid input and unbound search can raise. HTTP timeout bounds an await, not worker cancellation; the stricter 300-ms completion rule is opt-in. No universal no-throw or latency guarantee follows ([RT-RTE-context-delivery](runtime.md#rt-rte-context-delivery)).

### Assessment at this boundary

The strongest supported learning-related contribution is an automatic conversation-trace-to-durable-graph-to-later-context path. It consolidates session material into standing content and gives retained experience force at the updater and selected prose advisory force at later models. This supports wired trace-fed memory formation without requiring weight training or demonstrated improvement. It does **not** establish improved capacity for future action, semantic faithfulness, or a produced and accepted ampliative claim ([MEM-OBJ-derived-points](memory.md#mem-obj-derived-points), [WF-RTE-gap-review](workflow.md#wf-rte-gap-review), [RT-BAP-framework-block](runtime.md#rt-bap-framework-block), [profile verification](profile-verification.md#verification)).

For continuity across sessions, the inspected architecture supplies concrete retention and delivery mechanisms. For a scenario requiring every recalled statement to carry verified support, every withdrawal to reach every reader, or failures to leave no partial writes, these mechanisms do not establish the required guarantees. This is a scenario-relative distinction, not a product ranking.

The accepted runtime does not supply separate theory-builder condition assessments. Condition 1 (localized formulated theory), condition 2 (decisions depending on its content), condition 3 (content-directed criticism with blame and changed reliance), and condition 4 (retained criticism shaping another round) are each unestablished as theory-route findings here; graph claims and S4 candidate review do not by themselves close those requirements. No improvement caused by criticism of a consumed theory is established. Reflection's two causal directions and role-complete autonomous theory building likewise remain unestablished, independently of automatic write progression. Exercised self-improvement of the bounded system is not established: retained context can reach later behavior, but subsequent operation causally depending on an evidence-responsive organizational change, against an independently stated improvement objective, is not shown. These are evidence limits, not system-wide absences ([runtime account](runtime.md#runtime-account), [epistemic bounded conclusion](epistemic.md#bounded-conclusion)).

Paired transcript/claim assessments would change the semantic-fidelity finding; independently validated parameter provenance and calibration could change the confidence interpretation. Consumer traces following retained content through selection into subsequent decisions would establish activation beyond delivery. An objective-linked intervention and comparison could assess improved capacity and self-improvement without attributing an effect more finely than the intervention. All-path tracing or changed reader predicates would be needed for stronger withdrawal, consent and recovery guarantees. No additional source reads were needed for this synthesis.
