## Bounded conclusion

The package separates retained candidates from page endorsements in doctrine. Entry prose is preserved before acceptance; agents are asked to review predecessors and expose counterexamples. Historical imports can preserve text without reconstructed evaluation lineage: source warrant is unknown. Candidate authorship and crystallization are semantically indeterminate without a concrete input/output pair; novelty does not establish non-entailment or warrant. See [EPI-RTE-entry-authorship](#epi-rte-entry-authorship), [EPI-RTE-entry-retention](#epi-rte-entry-retention), [EPI-RTE-archival-import](#epi-rte-archival-import), [EPI-RTE-peer-judgment](#epi-rte-peer-judgment).

Closure uses attributed N/C/R maturity and User Recognition; structural canon separately uses revision review, full active consensus or a two-thirds soft quorum, waiting conditions, no dispute and explicit user approval. Significant changes and revision mismatch withdraw endorsement in doctrine; disputed soft canon returns to working. These are intended-use admission criteria for structural knowledge, not supplied evidence-consuming acceptance of a particular proposition. No actual accepted ampliative claim or completed lifecycle integration is established. Canon remains an external author/agent/user responsibility. See [RT-RTE-canon-admission](runtime.md#rt-rte-canon-admission), [EPI-RTE-canon-review](#epi-rte-canon-review), [EPI-RTE-canon-integration](#epi-rte-canon-integration).

The executable produces truth-apt diagnostic propositions by entailed derivation from local file observations under fixed predicates. Its license ends at those predicates: numerical sum consistency does not validate peer scores; consensus presence does not validate consent; signature-field presence does not authenticate; link existence does not warrant linked content. Findings become current process failure only through collected HARD count and normal CLI completion; repair text remains advisory, and downstream work blocking requires an external caller honoring the exit. Direct method calls and parser/I/O failure are different routes. See the five checker parts and [RT-BAP-audit-exit](runtime.md#rt-bap-audit-exit).

Countercase deductions use implementation, not target execution. A Markdown page whose missing-file link occurs only in inline code loses that link in `strip_markdown_code` before L1 link matching, so no missing-link finding follows from that occurrence. A heading inside a fenced block nevertheless enters the unstripped heading index and can satisfy a cross-page anchor check. An index merely containing a concept's name as prose passes that concept's substring presence test. These cases limit each relevant predicate, not all audit checks. See [EPI-RTE-hygiene-graph](#epi-rte-hygiene-graph). In a non-archival two-entry chain with first contribution and second closure whose last_eval is N=.2, C=.3, R=.4, accumulation becomes (.2,.3,.4); a declared N=.22 differs by more than .01 and produces D6 regardless of whether .2 is a justified Novelty judgment. See [EPI-RTE-vector-check](#epi-rte-vector-check). This is arithmetic evidence, not new knowledge about the discussed domain. The shipped participation instructions disagree: SRC-1 `protocols/rolespace-coordination.md` says to sum contribution/reopen evaluations only, while `protocols/dialogue-thread-format.md` includes closure. The implemented closure-inclusive calculation remains supported, but no run evidence establishes which instruction agents follow or that all shipped instructions yield the same deficit after closure/reopening.

>     - Calculate the `current` vector (sum of `last_eval` for all contribution/reopen entries).
> --- `protocols/rolespace-coordination.md`

> current = Σ entry.last_eval.v for all entries where type ∈ {contribution, reopen, closure}
> --- `protocols/dialogue-thread-format.md`

Semantic review, report/log retention and contested-Hard user decisions are doctrine only. Raw-source immutability has no baseline/comparison or approval checker. Persona Recognition is an identity doctrine, not an operationally testable subjectivity oracle in the supplied evidence. See [EPI-RTE-semantic-review](#epi-rte-semantic-review), [EPI-ABS-source-check](#epi-abs-source-check), [EPI-OBJ-anchor-form](#epi-obj-anchor-form).

Deficit-directed attention supplies advisory direction selection. Separately, cross-thread zhat refinement produces a truth-apt working estimate of an agent's participation orientation, not an assessment of contribution truth. Normalization derives a numeric summary from selected attributed scores; those scores do not by themselves warrant a natural-orientation claim. Its semantic relation remains indeterminate without a specified estimation scope and interpretation. Subsequent preferred-direction use is advisory, not evidence-consuming acceptance of the estimate; its writer, calibration, actual updates and behavioral activation remain unestablished. See [EPI-RTE-zhat-update](#epi-rte-zhat-update) and [MEM-RTE-profile-refinement](memory.md#mem-rte-profile-refinement). Reported formula repairs retain criticism and changed rules, but establish neither exercised self-improvement nor improved future capacity. Learning, reflection, autonomy and theory-builder conditions retain the separate bounded assessments in [RT-RTE-thread-participation](runtime.md#rt-rte-thread-participation) and [RT-RTE-package-revision](runtime.md#rt-rte-package-revision). External distributed-parametric state is uninspected; text retention and protocol revision imply no parameter learning. There is no single system-wide epistemic score or unqualified verdict.
