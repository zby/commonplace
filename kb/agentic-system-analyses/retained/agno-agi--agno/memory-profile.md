# Agno memory profile

## Comparison rationale

### Boundary, coverage and evidence strength

This revision-2 profile classifies accepted records, not a deployed Agno instance. Every axis is partial because the included inventory retains opaque/custom alternatives or missing initial-control, payload or later-consumer facts. A known built-in unit means complete classification only within its explicitly named operation or part. It does not certify all adapters or branches. The inventory limits attached to [MEM-OBJ-agent-session](memory.md#mem-obj-agent-session), [MEM-RTE-learning-context](memory.md#mem-rte-learning-context), [MEM-RTE-knowledge-context](memory.md#mem-rte-knowledge-context) and [WF-RTE-sequential-delivery](workflow.md#wf-rte-sequential-delivery) prevent whole-runtime memory completeness. No observation or causal evidence supports stronger bases than wiring; documented external/manual consumer roles remain afforded.

Component versions changed and subsequently consumed through [RT-RTE-config-admission](runtime.md#rt-rte-config-admission) are retained behavior-shaping state. Static cookbook prompts, skills and registered executable code are not accumulated memory. Work-queue storage is not substituted for this memory boundary. [EPI-RTE-sft-selection](epistemic.md#epi-rte-sft-selection) contributes retained exported examples and score-consuming admission, but not an established trainer or updated model weights. Provider inference components describe numerical implementation, not evidence that use updates those weights.

### Forms, provenance and forces remain local

Dense knowledge embeddings are parametric representations in vector storage; symbolic IDs/metadata and natural-language document text remain separate parts. [MEM-OBJ-learned-knowledge](memory.md#mem-obj-learned-knowledge) does not make embedding provenance fully known. [MEM-OBJ-result-store](memory.md#mem-obj-result-store) likewise distinguishes opaque payload, access index and preview. Classifying its readable preview does not classify the entire preserved string. Filesystem knowledge and opaque media/provider state retain uncertainty rather than receiving values from adjacent inspected branches.

Preferences and organizational directives can supply instruction, while facts, evidence and continuity supply knowledge. Their system-message placement alone does not determine the force. Existing conversations/context additionally supply learning at extraction/summary update consumers, independently of downstream knowledge or instruction. [MEM-BAP-retained-context](memory.md#mem-bap-retained-context), [EPI-RTE-learning-extraction](epistemic.md#epi-rte-learning-extraction) and [EPI-RTE-learning-recall](epistemic.md#epi-rte-learning-recall) support these different paths. Retained text/vectors/aliases affect retrieval ranking even without a learned ranking policy. Entity retirement markers enforce ordinary-display withdrawal; their historical retention makes that curation invalidation rather than erasure.
