The existing routing value remains supported independently by checkpoint continuation; this omission changes neither that union value nor its wired basis.
- The profile's partial curation inventory classifies client reset but omits the separately implemented `set_history` replacement described by [MEM-RTE-chat-history](memory.md#mem-rte-chat-history) and [MEM-OBJ-messages](memory.md#mem-obj-messages). Replacement revises existing retained conversation independently of whether caller control is human or computational. The [profile rationale](memory-profile.md#comparison-rationale) and unresolved write-agency unit preserve that control uncertainty, but consumers should not treat the curation units as a complete inventory of client-history maintenance. The emitted evolve value already has a supported wired reference-replacement witness; no system-level value or evidence basis changes.
