For the seven runtime routes, I checked turn dispatch, branch context cloning, task-bound versus reference-only spawning, finalization ordering, OpenCode permission handling, autonomy level admission, context reduction, skill rails and configuration reload. Implementation findings remain `wired`; operation remains `uninspected`. The task approval gate is not universal action approval ([RT-RTE-delegated-work](runtime.md#rt-rte-delegated-work), [RT-RTE-opencode-work](runtime.md#rt-rte-opencode-work), [RT-RTE-autonomy-epoch](runtime.md#rt-rte-autonomy-epoch), [RT-CLM-role-grants](runtime.md#rt-clm-role-grants)).
