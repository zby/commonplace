This supports both [RT-RTE-source-ingest](runtime.md#rt-rte-source-ingest) and the [workflow account](workflow.md#workflow-account), including its partial-staging and completion qualifications (SRC-1, `src/wiki/extract.py`, `src/wiki/ingest/pipeline.py`, `src/wiki/ingest/types.py`). It does not imply that an uncited page with no sources would be included by the CLI evaluator, which separately skips pages lacking sources. The report retains that selection condition (SRC-1, `src/wiki/validate.py`, `src/wiki/schema_loader.py`, `schema/v1/_base.schema.yaml`, `src/wiki/ingest/spancheck.py`, `src/wiki/eval/ingest_eval.py`, `src/wiki/cli/__init__.py`).
