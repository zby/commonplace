The profile classifies specified retention and later consumption, not successful operation. Model-operated writes, selection and maintenance have a claimed basis. Inspected shell copying has a wired basis. Exported helper consumption remains afforded: neither export nor a proposed two-way test establishes an actual call. All profile object citations use those canonical memory declarations: comments, session history, handoff, tasks, decisions, lessons, QA, sidecars, helpers and audits. The distinct epistemic check/admission/inference/filter parts and runtime producer containers remain valid. Supersession does not upgrade an evidence basis or erase epistemic limits. Project records supply knowledge; decisions and directives supply instruction; experience has learning authority at an update consumer; clean-state/index/address metadata supplies routing or validation. A helper's possible enforcement is kept at its documented future caller. No shell gate is inferred from imperative prose. Relevance selection alone is not ranking. The helper and backup branches retain missing-consumer limits rather than borrowing the startup consumer of a different object.
