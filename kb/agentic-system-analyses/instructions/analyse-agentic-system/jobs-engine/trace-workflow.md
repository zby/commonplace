# Trace a representative workflow

Explain how the source system coordinates a multi-step agent workflow through
to delivery, with the limits of what the evidence establishes.

Use `runtime` as a provisional baseline, not an inspection limit; the other
specialists work separately. Select one representative workflow from the
frozen source and trace its consequential handoffs and decisions. Check a
failure or rejection path where the source supports one. If no workflow can
be established, report that bounded result rather than constructing one.
