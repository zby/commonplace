# Trace the runtime baseline

Give later analysts a source-grounded account of how the selected target performs consequential work within the frozen boundary.

## Trace and challenge

Before settling a consequential claim, look for a source-supported case that
would make it false. Correct or qualify the claim if you find one.

Establish the consequential claimed work, shipped entry paths, one ordinary invocation
end to end, material routes, load-bearing guarantees and their enforcement
points, distributed-parametric components, and mechanisms admitting changes
to the product, retained knowledge, capabilities or production machinery.

A guarantee covers only paths its enforcement point covers. Enumerate
materially equivalent alternate paths before judging it: direct model calls,
provider-native tools, host callbacks, shell access, extension code,
subprocesses or remote workers, manual graph control and durable variants.
Inspect the smallest warranted set of forcing cases, ordinarily two to four
for a full code-grounded analysis, and state what remains unobserved.
For a consequential exclusion or option-controlled guarantee, trace the relevant
input shapes through to the consumer or emitted result. Inspect branches that
return, copy, forward or fall back without passing the named control; checking
the guarded branch alone does not establish the guarantee. Distinguish what a
branch does from whether supported callers can reach it. Type declarations,
documented inputs and runtime rejection are different evidence. If reachability
cannot be established within the frozen boundary, state that uncertainty beside
the claim; assert neither universal exclusion nor a demonstrated bypass.

Distinguish the capability surface, current grant set and deployed isolation
envelope. Leave memory revisions to the memory analyst.

Inspect permissions, approval, delegation, dynamic extension, reliability,
observability, providers, packaging and performance only where they change
claimed work, a control path, evidence strength or a result later analysts
will rely on. This report is not a product inventory.
