# Agentic-system analyses

Accepted analyses explain each external system at a frozen source boundary.
The overview links the synthesis, limitations and analyst members, including
a representative multi-step workflow through delegation, verification,
recovery and delivery where the evidence supports one.

The site generates the current-analyses list from `retained/`. Systems enter
this population through newly commissioned runs. Historical sets under
`kb/agentic-systems/reports/` remain outside it.

Authors read [the collection contract](./COLLECTION.md). Coordinators follow
[publication](./instructions/publish-analysis.md). Method authors follow
[method maintenance](./instructions/maintain-analysis-method.md).
