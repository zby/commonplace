# Agentic-system analyses

These analyses supply concrete cases for [design-space exploration](../agentic-systems/README.md):
identifying relevant choices, investigating possible combinations, separating
established constraints from uncertain ones, and deciding what evidence would
justify a design commitment. Start with the [research topics](../agentic-systems/topics/README.md)
for questions and future work, or [comparisons](../agentic-systems/comparisons/README.md)
for cross-system accounts.

Accepted analyses explain each external system at a frozen source boundary.
They establish what the inspected sources support, not the full space of
possible designs or which design Commonplace should adopt.
The overview links the synthesis, limitations and analyst members, including
a representative multi-step workflow through delegation, verification,
recovery and delivery where the evidence supports one.

The site generates the current-analyses list from `retained/`. Systems enter
this population through newly commissioned runs. Historical sets under
`kb/agentic-systems/reports/` remain outside it.

Authors read [the collection contract](./COLLECTION.md). The operator's session
running the analysis skill follows
[publication](./instructions/publish-analysis.md). Method authors follow
[method maintenance](./instructions/maintain-analysis-method.md).
