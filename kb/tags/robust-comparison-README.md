# robust-comparison

A robust comparison ranks two versions of a system only where every measure compatible with the purpose of the work agrees. The defining note is [necessary preference can guide improvement without a global measure](../theory/necessary-preference-can-guide-improvement-without-a-global-measure.md). Assign this tag to work on that comparison: which measures are compatible and how that set is argued, what a claim of improvement asserts, how a disputed comparison is examined, and how to decide when the comparison stays open. Reporting that one version scored higher on a benchmark is insufficient. The subject must be a comparison that holds across a set of measures, or what to do when it does not.

[Evaluation](./evaluation-README.md) is the wider area of judging claims, changes and outputs; this tag covers one comparison rule inside it. [Improvement-loop](./improvement-loop-README.md) covers the loop that proposes and selects changes; a robust comparison is one way that loop can evaluate a candidate.
