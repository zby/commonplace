# Judgment-governed self-improvement

This tag keeps the former name of [selection-based learning](../theory/definitions/selection-based-learning.md): learning in which each change to what a system retains for its later work is proposed, judged and can be rejected. Assign this tag to work on that process: the decision that defines it, the judgment that decides a change when no single criterion settles it, the single-loop and double-loop kinds, correction from later evidence, whether one change made the system better, or the claim that a fully automated selection-based learner is a machine learning paradigm. Work on a system that only retains readable artifacts is insufficient. The subject must be how a change is decided, how that decision is judged later, or whether an automated selection loop scales as a learning paradigm. Tagging an analysis does not certify that the analyzed system learns.

The draft article [Selection-Based Learning Without a Value Function](../articles/selection-based-learning-without-a-value-function.md) argues the thesis for outside readers, and the companion draft [Testing Autonomous Selection-Based Learning](../articles/testing-autonomous-selection-based-learning.md) states the research program and comparisons that test it. Commonplace's bet is that a language model with fixed weights can make the judgment with no person judging. No end-to-end test of the bet has been run.

Two neighbors are close. [Improvement-loop](./improvement-loop-README.md) covers proposal and selection whatever form the retained result takes; this tag covers that loop as a kind of learning: the judgment itself, its criterion, and what happens to a change afterwards. [Continual-learning](./continual-learning-README.md) covers learning outside model weights whether or not a decision admits each change. A note that meets two conditions can carry both tags. This tag is a child of [self-improving-systems](./self-improving-systems-README.md).

## Definition

- [Selection-based learning](../theory/definitions/selection-based-learning.md) — the decision that defines it, the cases it includes and excludes, and what a claim names
- [Single-loop and double-loop learning](../theory/definitions/single-loop-and-double-loop-learning.md) — the two kinds, separated by whether the learner can revise the criterion that decides a class of changes
