# artifact-analysis

[Artifact analysis](../theory/axes-of-artifact-analysis.md) classifies retained artifacts by storage substrate, representational form, lineage, and behavioral authority. Assign this tag to work that defines, extends, tests, or draws design consequences from the scheme or an individual field. An application of one field qualifies when the distinction changes a design or maintenance conclusion; it need not address all four. Merely mentioning storage or artifacts, or filling in the fields without drawing a consequence, is insufficient. [Document-system](./document-system-README.md) covers writing and checking documents; this tag covers retained artifacts across forms. A child of [learning-theory](./learning-theory-README.md).

## Definitions

- [Retained artifact](../theory/definitions/retained-artifact.md) — persisted state consumed with behavioral consequences
- [Operative part](../theory/definitions/operative-part.md) — the behavior-affecting portion or mechanism
- [Storage substrate](../theory/definitions/storage-substrate.md) — where retained state persists
- [Representational form](../theory/definitions/representational-form.md) — encoding and consumption determine the default review method
- [Lineage](../theory/definitions/lineage.md) — source dependencies determine refresh and review obligations
- [Behavioral authority](../theory/definitions/behavioral-authority.md) — consumer, channel, and force
- [Knowledge artifact](../theory/definitions/knowledge-artifact.md) — consumed as evidence, reference, explanation, or advice
- [Answerability](../reference/definitions/answerability.md) — nameable referent, asserted property, and correction-triggering discrepancy
- [System-definition artifact](../theory/definitions/system-definition-artifact.md) — consumed with binding operational force
