Instruction preservation has a concrete source-inspected defect. In rules mode, `please never use tabs` maps to `User requested: use tabs`, because the preference template omits the matched negative qualifier. Separately, overlap-based deduplication drops words including `not`, `no` and `never`, so opposed assertions can appear equivalent to that check. These are implementation deductions, without an executed incident here. They matter particularly when remembered preferences become later instructions: source quotation alone cannot repair a changed instruction's meaning. ([RTE-4 annotation](../reports/retained/AAS-2026-10-01-instinctual-memory-07/memory.md), [RTE-4 amendment](../reports/retained/AAS-2026-10-01-instinctual-memory-07/reconciliation.md), [RTE-9](../reports/retained/AAS-2026-10-01-instinctual-memory-07/runtime.md).)

Requested search combines curated facts and journal events, with optional remote relevance judging, a cached local reranker, then lexical fallback. Project filtering occurs after the bounded fact shortlist, so unrelated facts can consume candidate slots; direct ID reads do not apply a project predicate. Project selection therefore provides retrieval scope rather than tenant isolation. Automatic host delivery uses different selectors: session start reads only the exact preference entity and emits at most twenty statements, while prompt callbacks emit at most six lexical matches after prompt and overlap gates. These callbacks emit advisory context; project writeback persists selected statements in a managed instruction block. Host incorporation and behavioral activation remain uninspected. ([RTE-1, RTE-2, RTE-5, BAP-1, BAP-2](../reports/retained/AAS-2026-10-01-instinctual-memory-07/runtime.md), [RTE-5 amendment](../reports/retained/AAS-2026-10-01-instinctual-memory-07/reconciliation.md), [MEM-OBJ-1](../reports/retained/AAS-2026-10-01-instinctual-memory-07/memory.md).)

For a scenario requiring a forgotten or expired statement to disappear from every later context, the consumer differences are decisive. Search applies temporal eligibility and fact controls. Direct entity reads select active-status facts after suppression/deletion filtering but omit search's time and audience checks; session-start delivery inherits that behavior. Writeback has its own status and fact-visibility filters, permits disputed facts, and omits controls, entity visibility and temporal eligibility. A previously written block survives subsequent store changes. Soft forget also leaves raw journal content searchable. Hard erasure extends removal to selected journal, history and intent material through successive fallible steps, with external transcripts and file copies outside its reach. These paths support local withdrawal, without a uniform all-context or whole-environment erasure guarantee. ([RTE-2, RTE-6 amendments](../reports/retained/AAS-2026-10-01-instinctual-memory-07/reconciliation.md), [RTE-3, RTE-9](../reports/retained/AAS-2026-10-01-instinctual-memory-07/runtime.md), [MEM-OBJ-1](../reports/retained/AAS-2026-10-01-instinctual-memory-07/memory.md).)
