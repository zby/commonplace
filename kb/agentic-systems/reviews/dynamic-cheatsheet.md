At reviewed commit `5cfe3c37e8e52b1d858d0f3df46e7f17c50991b9`, Dynamic Cheatsheet is a query-time memory and retrieval library. The caller supplies a question, prompt templates, any current cheatsheet, and, for retrieval, aligned prior examples and embeddings. The wrapper calls a configured model to generate an answer, then in cumulative modes asks that model to propose a cheatsheet update. The library returns the proposed text; a caller must retain and resubmit it for use in a later call. Its code therefore affords caller-mediated accumulation rather than providing durable storage itself ([runtime.md], RT-RTE-1, RT-RTE-3; [memory.md], RT-OBJ-1).

The routes differ in how they assemble context. Cumulative generation reuses a supplied cheatsheet and can pass an extracted update to later rounds in the same call. Full-history appending places all supplied prior pairs in the prompt. Retrieval-only and cumulative retrieval rank supplied examples by cosine similarity; retrieval synthesis first asks the model to form a query-specific sheet from selected examples. These selectors establish ordering in the supplied vector space, not correctness or answer quality. The embedding producer, vector provenance, and example alignment are outside the inspected boundary ([runtime.md], RT-RTE-1, RT-RTE-2, RT-RTE-3, RT-RTE-4, RT-RTE-5; [memory.md], MEM-OBJ-1, MEM-OBJ-2).

In cumulative modes, tag extraction is the content admission check: a tagged model response replaces the in-call sheet, while missing tags retain the previous value. The check does not assess truth, evidence, or intended use; an empty tagged body can also replace the sheet. For retrieval synthesis, the missing-tag fallback is the formatted retrieval view, not the prior cheatsheet supplied to the curator.
