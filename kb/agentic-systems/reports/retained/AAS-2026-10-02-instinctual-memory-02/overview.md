## Bounded synthesis

Instinctual-memory ships the Rust library and CLI `mem`, a durable memory service for external coding agents. This analysis covers its whole source system at commit `6acb13dc35765bf5ccfc87e445dd09c480f1c28a`, including target-side integration, but excludes the agents' dialogue loops and external inference implementations. Its declared work is to curate sourced facts from earlier conversations and project files, then expose search, changes and project-file delivery. The evidence establishes implementation mechanisms; no supplied run or experiment demonstrates reliability or benefit. [EPI-CLM-1](epistemic.md), [RTE-1](runtime.md), [CMP-1, CMP-2, CMP-3](runtime.md).

The operational progression starts with acquisition into a raw JSONL journal. Transcript/file adapters also include calendar and timestamped voice inputs. Consolidation reads beyond a retained checkpoint and proposes standing facts using rules or a configured model. User turns and Note events can feed extraction; assistant and tool-role events do not qualify on the inspected extraction paths. Selected facts, source links, index, checkpoint and dispositions enter a Git snapshot for later retrieval. Explicit remember/correct requests provide another write path. Retained controls can veto proposal IDs, while the checkpoint chooses future extraction windows. These parts have different consumers and effects despite sharing one snapshot. [OBJ-2, RTE-10, RTE-3, RTE-2](runtime.md), [annotations on OBJ-1 and RTE-3](memory.md), [reconciliation of OBJ-1 and amendment of RTE-10](reconciliation.md).

The strongest supported learning contribution is an implemented chain from retained experience to durable facts available to later queries and hooks. This is automatic trace-fed memory production, not demonstrated improvement in capacity for future action. Semantic fidelity remains unresolved. The model path checks statement shape, a model-supplied durability flag and ordered normalized quote fragments in a cited event; it does not check whether the statement follows from that evidence or whether the source is true. Rules and explicit changes do not share this occurrence gate. Lexical deduplication can disregard negation, and an event marked accepted can contain a proposal dropped before insertion. Persistence, source attribution and these operational labels therefore give different evidence from a truth endorsement. [annotation on RTE-3 and Comparison rationale](memory.md), [EPI-OBJ-1 and RTE-3 ledger functions](epistemic.md), [RTE-2, RTE-3](runtime.md), [reconciliation of OBJ-1](reconciliation.md).

Normal candidate publication validates before comparing and swapping the Git memory branch. This protects that branch update under Git's contract; it does not make the journal, task files, exports and all erasure stages one transaction. Public library users choose their validator. The shared operation dispatcher also acknowledges an existing request receipt before comparing the new payload, so the lower publisher's digest conflict check is not a universal replay guarantee. [RTE-2, RTE-6, RTE-7, RTE-8, RTE-10](runtime.md), [EPI-CLM-3](epistemic.md).

Requested retrieval combines curated facts and raw journal hits, with optional remote relevance judging, local reranking and lexical fallback. Relevance ranking does not verify truth. Automatic hooks supply a narrower context: startup reads the preference entity, while prompt hooks select at most six facts using lexical overlap. Project writeback renders selected facts into a persistent managed block. All three channels supply information or guidance to an excluded host; emitted text does not establish host consumption or changed behavior. [RTE-1, RTE-5, RTE-8, BAP-1](runtime.md), [annotations on RTE-1, RTE-5 and RTE-8](memory.md).

Withdrawal depends on the consumer. Curated lexical search checks controls and temporal eligibility when timestamps are populated; ordinary producers leave expiry unset. Startup preference reads filter Active enum status, while writeback uses its own status/visibility predicate and can export disputed or temporally expired content. Prior exports have no automatic retraction. Tidy proposes duplicate withdrawals through deterministic overlap and session-only withdrawals through an optional model judge; the operator chooses apply and can keep individual facts. Forget and tidy alter status/controls, whereas erasure separately removes current content, redacts linked journal material and rewrites history. None of these actions establishes that the removed statement was false. [amendments of RTE-2, RTE-3, RTE-4, RTE-5 and RTE-8](reconciliation.md), [RTE-6](runtime.md), [EPI-OBJ-2 and withdrawal ledger functions](epistemic.md).
