# Archived single-file agentic-system analysis results

Retained results produced by `analyse-agentic-system` under the single-file
result type before the method moved to a set of member documents per run
(workshop `kb/work/agentic-analysis-output-documents`, archived
2026-09-28). Each run directory holds the exact `result.md` bytes that its
review pinned at publication; the pins in
`kb/agentic-systems/reviews-archive/` still verify against these bytes.

No producer, validator or comparison loader reads this directory. The
results are kept because the reviews, workshop records and trial reports
that cite them need the exact record behind the citation. A system listed
here is re-analysed as a fresh run under the current method; the new set
is retained under `kb/reports/retained/agentic-system-analysis/`, and the
archived run is not migrated.
