# Runtime lens

Cross-system pages for the runtime member of each current
[agentic-system analysis](../../../agentic-system-analyses/README.md). The
member traces how each system performs consequential work: model and tool execution, scheduling, context assembly, permissions and external state. Each analysis is frozen at its own source boundary;
the per-system accounts stay in their analysis sets, and this directory links
to them.

The analyst job that writes the member: [the runtime baseline](../../../agentic-system-analyses/instructions/analyse-agentic-system/jobs/trace-runtime.md).

No comparison fields exist for this lens yet, so it has no table or summary.
