# Workflow lens

Cross-system pages for the workflow member of each current
[agentic-system analysis](../../../agentic-system-analyses/README.md). The
member traces how each system coordinates one representative multi-step agent workflow through delegation, verification, recovery and delivery. Each analysis is frozen at its own source boundary;
the per-system accounts stay in their analysis sets, and this directory links
to them.

The analyst job that writes the member: [a representative workflow](../../../agentic-system-analyses/instructions/analyse-agentic-system/jobs/trace-workflow.md).

No comparison fields exist for this lens yet, so it has no table or summary.
