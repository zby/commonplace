# Epistemic lens

Cross-system pages for the epistemic member of each current
[agentic-system analysis](../../../agentic-system-analyses/README.md). The
member traces whether and how each system acquires or produces truth-apt content, checks it, grants reliance and lets it affect later behavior. Each analysis is frozen at its own source boundary;
the per-system accounts stay in their analysis sets, and this directory links
to them.

The analyst job that writes the member: [the epistemic routes](../../../agentic-system-analyses/instructions/analyse-agentic-system/jobs/trace-epistemic.md).

No comparison fields exist for this lens yet, so it has no table or summary.
