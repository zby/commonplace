# Refinement

Write "program refinement" or "refinement step" for the technical relation and never the bare word. Bare "refinement" stays ordinary English for iteration.

## Senses

Technical, compound only: [program refinement](../../theory/definitions/program-refinement.md), the ordering under which one artifact's permitted behaviors lie inside another's. Ordinary: prompt refinement, note refinement, in-place refinement, meaning iterative improvement, in about forty-five library files. Theory refinement: the EITHER and FORTE repair line cited by [addressable theory](../../theory/definitions/addressable-theory.md).

## Why these uses are retained

The technical sense is always written as the compound, and iteration is never called "program refinement".

## When to reconsider

A bare "refinement" is used for the narrowing relation in a title, definition or description, or "program refinement" is used for editing toward a better artifact.
