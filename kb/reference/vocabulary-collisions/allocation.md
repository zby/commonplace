# Allocation

Always name the object: "function allocation", "search allocation", "effort allocation".

## Senses

Function allocation: which decision-bearing functions humans or computation supply ([reallocation note](../../theory/computationally-directed-self-improvement-is-a-reallocation.md)). Search allocation: distributing search across branches ([allocation note](../../theory/open-ended-improvement-allocates-search-before-evaluation.md)). Effort allocation: dividing effort among investments.

## Why these uses are retained

All three allocate something, and naming the object disambiguates.

## When to reconsider

A bare "allocation" appears in a title, definition, or frontmatter description with one sense assumed.
