# Deliberative

Do not use "deliberative" as a technical term. Write "selection-based learning", linked to the definition, for what was named "deliberative learning" until 2026-11-22. Write "deliberative agent" or "deliberative democracy" in full when those senses are meant.

## Senses

Retired technical sense: "deliberative learning" named what is now [selection-based learning](../../theory/definitions/selection-based-learning.md), learning in which each change to what a system retains for its later work is proposed, evaluated and can be rejected. Agent architectures: a deliberative agent holds an explicit symbolic model of the world and decides by reasoning over it ([Wooldridge and Jennings](../../sources/wooldridge-jennings-intelligent-agents.ingest.md)). Political theory: deliberation by a group that weighs competing arguments ([Fishkin and Mansbridge](../../sources/fishkin-mansbridge-deliberative-democracy-intro.ingest.md)). Everyday: careful or slow.

## Why the technical sense was retired

"Deliberative" was chosen for the shared image of weighing. The definition also covers a system with one fixed measure, which applies it and weighs nothing, so the name promised more than the definition required. "Selection-based" names the mechanism and does not tie the term to self-improvement. The two draft articles on the thesis still carry "deliberative learning" in their titles.

## When to reconsider

A library note uses "deliberative" as a technical term, or the draft articles are retitled.
