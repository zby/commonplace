# Deliberative

Use "deliberative" as a technical term only in "deliberative learning" and "deliberative learner", linked to the definition. Write "deliberative agent" or "deliberative democracy" in full when the other senses are meant.

## Senses

Technical: [deliberative learning](../../theory/definitions/judgment-governed-self-improvement.md) is learning in which each change to what a system retains for its later work is proposed, judged and can be rejected. Agent architectures: a deliberative agent holds an explicit symbolic model of the world and decides by reasoning over it ([Wooldridge and Jennings](../../sources/wooldridge-jennings-intelligent-agents.ingest.md)). Political theory: deliberation by a group that weighs competing arguments ([Fishkin and Mansbridge](../../sources/fishkin-mansbridge-deliberative-democracy-intro.ingest.md)). Everyday: careful or slow.

## Why these uses are retained

The technical term was chosen for the shared image of weighing. The agent sense names what is deliberated, an action, where the learner deliberates over changes to what it retains. The definition leaves open whether a deliberative learner is a deliberative agent. A deliberative learner with one fixed criterion applies it and weighs nothing, so the everyday sense does not follow from the technical one.

## When to reconsider

A library note uses "deliberative" for a system because it reasons carefully, or the relation between a deliberative learner and a deliberative agent is settled.
