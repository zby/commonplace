# Operational

Use `operationalized-from` only as a link label; gloss external senses on first mention with the ingest. For symbolic membership use [representational form](../../theory/definitions/representational-form.md), and for the move use [codification](../../theory/definitions/codification.md), following [ADR 124](../adr/124-retire-unique-operational-semantics-as-the-form-criterion.md). Do not use bare "operational" as an unregistered technical synonym for either.

## Senses

Lineage: `operationalized-from`, the methodology-to-procedure edge ([ADR 054](../adr/054-add-adapted-from-and-operationalized-from-lineage-relations.md)). External: programming-language operational semantics, rules specifying program transitions ([Plotkin](../../sources/plotkin-origins-of-sos.ingest.md)); operationalism, meaning by measuring operations ([operationalism](../../sources/operationalism-sep.ingest.md)). Ordinary: making something usable in practice.

## Why these uses are retained

The formal link label occupies a declared slot; external senses name their discipline. None supplies the Commonplace criterion for symbolic form.

## When to reconsider

A reader confuses the symbolic membership criterion with programming-language operational semantics or measurement operations.
