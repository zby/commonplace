# Storage automation and agent memory use remain separate findings

This three-system pilot distinguishes automatic storage work from evidence that an agent extracts and consumes retained knowledge. Dynamic Cheatsheet and Mem0 have implemented trace-fed memory writes and automatic supply to later model calls. Napkin has implemented file operations, imports and access-cache writes, while its agent extraction and recall workflows remain afforded by shipped instructions and documented integrations. These are differences in the retained evidence and selected boundaries, not a ranking of the products.

## What the selected evidence supports

Automatic writing has a wired witness in **3/3** selected systems, but implemented trace-fed derived memory has a witness in **2/3**, Dynamic Cheatsheet and Mem0. Push to a later model has wired or observed support in those same **2/3**. Napkin's trace extraction and push are afforded, so its exclusion from those implementation counts is not a negative finding. The query conjunction establishes co-occurrence within each system; it does not establish causal benefit or that any two arbitrary routes connect. The [query ledger](./trial-query-ledger.md) retains all 21 exact records, filters, denominators, included runs and exclusions.

Dynamic Cheatsheet's cumulative route sends the current cheatsheet to the generator, then asks a curator to replace it from the problem, output and old sheet. Retained examples show an earlier sheet in the next prompt. That is observed delivery; the same sample contains a wrong solution retained in the sheet. It does not show that recalled content caused a later answer or establish a general error rate. The curator's intended content criticism depends on supplying the inspected templates, and the extractor itself supplies no semantic veto. Evidence: **RTE-2, RTE-6, CLM-4**, in [Shared records](../agentic-system-analysis-archive/AAS-2026-09-26-dynamic-cheatsheet-02/result.md#shared-records).

Mem0's automatic consumer is its own extraction model: each inferred add supplies selected prior messages and fact text before generating additional facts. Public retrieval for an answering application is a separate afforded route. The ordinary extraction path adds facts; explicit caller operations own replacement and deletion. This is why internal push, external pull and correction cannot be inferred from one another. Evidence: **RTE-1, RTE-2, RTE-3, RTE-5, BAP-1, BAP-2**, in [Shared records](../agentic-system-analysis-archive/AAS-2026-09-26-mem0-02/result.md#shared-records).

Napkin's automatic imports and compiled search caches account for its wired automatic-write value. Its distill skill separately directs an external agent to turn session findings into lasting notes, preserve reasons and mark new generalizations. Requested overview/search/read is pull; documented whole-note session loading is coarse push, whose host implementation is outside the inspected package. Neither automatic indexing nor a requested search response supplies that missing implementation evidence. Evidence: **OBJ-8, RTE-7, RTE-8, RTE-10, RTE-11**, in [Shared records](../agentic-system-analysis-archive/AAS-2026-09-27-napkin-01/result.md#shared-records).

Both natural-language and symbolic retained parts have strong witnesses in **3/3** selected systems. This does not mean their learned outputs are identical: symbolic access metadata and query definitions count in representational form, while distilled form concerns the specific trace-fed transformation. Dynamic Cheatsheet also has partial aggregate coverage because included provider payloads remain opaque. Its supported positives count, but its value sets cannot enter complete-profile comparisons.
