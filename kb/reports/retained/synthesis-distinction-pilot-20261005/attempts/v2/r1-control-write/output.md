## Description

Dynamic Cheatsheet carries prompt-visible text and prior examples between model calls, with benchmark checkpointing; repository code shows delivery and scoring, but not model use or memory-caused gains.

## Bounded synthesis

The evidence is implementation inspection of the complete shipped repository at the registered SRC-1 revision, with declared prompt/design text; no hosted operation was observed ([boundary.md](boundary.md)). In the cumulative route, one configured model generates an answer and then proposes a full cheatsheet replacement. The extractor accepts tagged text or retains the previous text; the benchmark carries returned text into later eligible prompts and saves rows for continuation ([runtime.md#RT-RTE-cumulative-loop](runtime.md), [memory.md#MEM-RTE-cumulative-write](memory.md)). This is prompt-guided curation with a syntax fallback, not a verified correctness gate.

Other routes use selected prior input/output pairs, all prior pairs, or both pairs and cumulative text. Retrieval ranks prior inputs by cosine similarity over fixed precomputed vectors; it does not select on answer correctness. The benchmark can restore saved outputs and the latest cheatsheet, while direct retrieval does not consume its carried text field ([runtime.md#RT-RTE-retrieval-synthesis](runtime.md), [runtime.md#RT-RTE-direct-retrieval](runtime.md), [runtime.md#RT-RTE-full-history](runtime.md), [runtime.md#RT-RTE-checkpoint-resume](runtime.md), [memory.md#MEM-OBJ-example-history](memory.md), [memory.md#MEM-OBJ-embedding-table](memory.md)).

The benchmark compares answers with task targets after generation and curation, then updates counters; that score does not admit, reject, revise, or roll back answers or memory ([epistemic.md#EPI-RTE-benchmark-answer-check](epistemic.md)). These mechanisms establish prompt delivery and local persistence, not behavioral activation, answer correctness beyond the task predicate, improved future capacity, or memory-caused performance gains. The README’s learning and performance claims therefore remain unverified in this evidence set ([epistemic.md#EPI-CLM-performance-gains](epistemic.md), [epistemic.md#EPI-CLM-zero-shot-learning](epistemic.md)).
