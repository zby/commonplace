# Report state

Operational outputs of Commonplace workflows, one directory per workflow:
connect reports, review results, packets and runs, fix dispositions and
ingest working directories. Payloads here are ignored to keep generated and
unreviewed output out of the library's record, not because they are safe to
discard. Follow each producing workflow's authority, integrity and cleanup
rules, and record here what deleting each workflow's output loses.

This README is ignored by the main repository along with the workflow
outputs. The validation marker beside it belongs to the main repository.
Init creates this README but does not create a separate state repository;
choose backup or shared-repository arrangements explicitly.
